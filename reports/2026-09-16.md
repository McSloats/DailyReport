## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-57123 / CVE-2026-57124 — PraisonAI: Unauthenticated MCP Endpoints to Remote Code Execution**
CVSS 9.8 each. PraisonAI's UI and agent-tooling components bind their MCP (Model Context Protocol) servers to 0.0.0.0 by default without invoking the framework's own authentication, origin-validation, or DNS-rebinding checks. CVE-2026-57124: the UI's `/api/mcp/connect` endpoint accepts caller-controlled command/args and spawns an arbitrary local process, even if the MCP handshake later fails. CVE-2026-57123: the agents library's SSE/messages routes let any reachable client list and invoke registered tools — including shell and code-execution tools — with browser-based DNS rebinding extending the attack to local-only instances. No confirmed in-the-wild exploitation yet, but both require no authentication and are trivially reachable. **Fix:** upgrade PraisonAI UI to ≥4.6.59 and `praisonaiagents` to ≥1.6.59; don't expose these services to untrusted networks in the meantime.
Source: https://www.strix.ai/cve/CVE-2026-57124
