## Actively Exploited / CISA KEV

### CVE-2026-88771 & CVE-2026-88772 — NetScaler attackers now planting superuser backdoors and web shells disguised as CSS files (CVSS 9.5)
New intelligence on the Citrix NetScaler ADC/Gateway pre-auth RCE pair covered in this report's last two editions: researchers (LevelBlue THOR) found attackers deploying a second-stage Perl payload after initial compromise that creates a hidden superuser account, archives the appliance's configuration for exfiltration, and drops a PHP web shell renamed to look like a legitimate CSS asset so it blends into normal traffic logs. The script then changes `/bin/sh` permissions and deletes itself to cover its tracks.
**Fix:** If you have not already patched to NetScaler ADC/Gateway 14.1-73.37 or 13.1-64.23, do so now. On any appliance exposed between public disclosure and patching, audit for unexpected local/superuser accounts, unfamiliar `.css` files under web-facing paths, and changed permissions on `/bin/sh` — patching alone will not remove an existing backdoor.
Source: https://thehackernews.com/2026/10/citrix-netscaler-post-exploitation.html

### CVE-2026-104286 — Fortinet FortiMail path traversal hits its federal remediation deadline today (CVSS 9.8)
Covered in this report's Oct 2 edition: an unauthenticated path-traversal/NULL-byte flaw in FortiMail lets an attacker with access to the management interface write arbitrary files to the underlying system via crafted HTTP/HTTPS requests. Fortinet confirmed in-the-wild exploitation and CISA added it to KEV on Oct 1 with a federal civilian remediation deadline of today, Oct 4. Fixes remain "upcoming" for several affected branches (7.2.0–7.2.9, 7.4.0–7.4.8, 7.6.0–7.6.6, 8.0.0–8.0.1), leaving those versions reliant on workarounds.
**Fix:** If FortiMail is still on an affected branch without a released fix, disable Identity Based Encryption if not required and restrict management-interface access immediately; apply the vendor patch as soon as your branch has one.
Source: https://www.esecurityplanet.com/threats/news-fortimail-zero-day-cve-2026-104286-active-exploitation/

## General News

### Public PoC for Apple's "extremely sophisticated attack" zero-day points to WhatsApp as the likely delivery path
Follow-up on the CoreGraphics out-of-bounds write (CVE-2026-86950) patched Sept 29 after Meta reported it was used against specific targeted individuals: a public proof-of-concept has now surfaced showing a crafted PDF with a malformed embedded font triggers the bug, and researchers traced the in-the-wild sample to a credible WhatsApp-delivered PDF as the probable attack format. The PoC crashes unpatched devices but does not demonstrate code execution.
Source: https://securityaffairs.com/200175/hacking/public-poc-released-for-apple-coregraphics-zero-day-cve-2026-86950.html

### Technical University of Denmark breach exposes up to 200,000 current and former users
Attackers used compromised legitimate credentials to break into DTUBasen, DTU's identity and access management system, and downloaded records dating back to 2003 — including CPR (national ID) numbers, names, addresses, profile photos, work emails, and some next-of-kin details for roughly 40,000 active and 160,000 former students, staff, guests, and partners. DTU has referred the case to Denmark's data protection authority and national cybercrime police.
Source: https://cphpost.dk/2026-10-02/life-in-denmark/dtu-data-breach-may-affect-personal-information-of-200000-current-and-former-users/

### Biometrics vendor Aware, Inc. claimed by The Gentlemen ransomware group
The Gentlemen — one of 2026's most active ransomware-as-a-service operations, with over 330 published victims in the first five months of the year — listed US biometrics and identity-verification software vendor Aware, Inc. as a victim, claiming roughly 400GB of stolen data from an attack dated around Sept 30. Aware's SaaS platform orchestrates biometric identity workflows for about 80 government agencies and numerous commercial customers; it is unclear what customer data, if any, was exposed.
Source: https://www.hendryadrian.com/ransom-aware-oct-2026/

### Self-healing "SC" backdoor rebuilds itself across WordPress sites after cleanup
Sucuri researchers documented a WordPress malware family, nicknamed "SC," that hides redundant copies of its payload across files, the database, and shared memory — as many as eight locations at once — each capable of rewriting the others. Deleting the visible plugin or loader file is not enough: the next page load restores the full set from whatever copy survived, making standard incident-response cleanup ineffective without a full stack of file, database, and memory remediation.
Source: https://cybersecuritynews.com/wordpress-malware-2/
