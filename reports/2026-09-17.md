## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-12793 — JetFormBuilder (WordPress): Unauthenticated Admin Account Creation**
CVSS 9.8. The plugin fails to validate that a submitted form ID belongs to a genuine JetFormBuilder form before parsing the referenced post's content as form schema and executing a server-side validation callback, letting an unauthenticated attacker (via a crafted `_jet_engine_booking_form_id` parameter) create a new administrator-level account. Affects all versions through 3.6.2; published Sept 16. No confirmed in-the-wild exploitation yet, but public PoC code is already circulating. **Fix:** update JetFormBuilder to 3.6.2.1 or later immediately.
Source: https://www.strix.ai/cve/CVE-2026-12793
