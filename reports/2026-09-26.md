## Actively Exploited / CISA KEV

### CVE-2026-5430 — WSO2 API Manager & Gateway products, JWT auth bypass → RCE (CVSS 10.0)
WSO2's JWT authentication mechanism incorrectly validates tokens signed with algorithms it never explicitly configured, letting an unauthenticated attacker forge a JWT to bypass access controls; also enables path traversal and unrestricted file upload leading to RCE. WatchTowr recorded honeypot exploitation attempts dating back to September 13. Added to CISA KEV September 24.
**Fix:** Apply WSO2's patch (available since April). Federal deadline September 27.
Source: https://thehackernews.com/2026/09/wso2-and-adobe-commerce-flaws-exploited.html

### CVE-2026-65660 — Microsoft SharePoint Server, code injection RCE (CVSS 8.8)
An authenticated, low-privileged user can trigger code injection to execute arbitrary code remotely. Fixed in Microsoft's August 2026 update; CISA confirmed active exploitation and added it to KEV September 25.
**Fix:** Update to the August 2026 builds (SE 16.0.19725.20522 / 2019 16.0.10417.20198 / 2016 16.0.5565.1001). Federal deadline September 28.
Source: https://thehackernews.com/2026/09/sharepoint-rce-and-mikrotik-routeros.html

### CVE-2026-67279 — MikroTik RouterOS, "MikroTrick" SSH auth bypass → full admin takeover
RouterOS's SSH daemon enters the post-auth connection protocol after a client-requested rekey even though authentication never completed, letting an unauthenticated client execute commands. Chained with CVE-2026-86060 ("MikroTrick") for full admin control with no password. CERT Polska confirmed exploitation since at least September 2. Added to KEV September 25.
**Fix:** Update RouterOS to 7.25 beta 3 / 7.24.2 / 7.23.4 / 6.49.21 or later. Federal deadline September 28.
Source: https://securityaffairs.com/199777/hacking/u-s-cisa-adds-microsoft-sharepoint-and-mikrotik-routeros-flaws-to-its-known-exploited-vulnerabilities-catalog.html

### CVE-2026-87902 — WordPress Core, page-template file inclusion (CVSS 9.2) — continuity update
Reported here September 24 for active exploitation; CISA has now formally added it to KEV (September 25), confirming the federal remediation requirement.
**Fix:** Update to WordPress 7.1.2 or the matching backport. Federal deadline September 28.
Source: https://www.cyberkendra.com/2026/09/cve-2026-87902-wordpress-file-inclusion-rce.html

## Critical CVEs (NVD, CVSS ≥ 9.0)

### CVE-2026-93643 — Zimbra Collaboration Suite, path traversal → command execution (CVSS 9.8)
When OnlyOffice document editing is enabled, an unauthenticated attacker with access to a supported public Briefcase document can abuse unsigned save-path fields to write files outside the intended directory and execute commands as the `zimbra` user. No confirmed in-the-wild exploitation yet.
**Fix:** Upgrade to ZCS 10.1.21 or later; disable OnlyOffice integration if patching is delayed.
Source: https://www.strix.ai/cve/CVE-2026-93643

### CVE-2026-12227 — Visual Composer Website Builder (WordPress plugin), unauthenticated LFI → RCE (CVSS 9.8)
Versions up to 45.16.0 honor an attacker-controlled `vcv-template` parameter during WordPress's template-include handling, allowing an unauthenticated visitor to include and execute arbitrary local PHP files. A public PoC exploit is already circulating on GitHub.
**Fix:** Update to a version above 45.16.0 immediately.
Source: https://www.strix.ai/cve/CVE-2026-12227

## General News

### Kiteworks warns of "imminent" attack, urges customers to shut down servers
Secure file-transfer vendor Kiteworks told customers it received "credible threat intelligence from law enforcement" indicating an attack on Kiteworks systems may be imminent this weekend, asking all customers — including internally isolated servers — to power down for a six-hour window (02:00–08:00 UTC Saturday). Given the pattern of prior secure-file-transfer attacks (MOVEit, GoAnywhere, Accellion), Kiteworks operators should treat this as high priority and watch for a formal advisory.
Source: https://www.bleepingcomputer.com/news/security/kiteworks-urges-6-hour-server-shutdown-over-potential-zero-day-attacks/

### Pentagon HR system breach exposes Social Security numbers of ~4 million personnel
Unauthorized users accessed a vulnerable Defense Manpower Data Center server starting last October; undetected for roughly nine months until discovered and remediated in July. Exposed data includes Social Security numbers plus at least one other identifier for an estimated four million current/former DoD personnel. No indication of misuse so far; attribution unknown.
Source: https://www.cnn.com/2026/09/25/politics/pentagon-data-personnel-breach
