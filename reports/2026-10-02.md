## Actively Exploited / CISA KEV

### CVE-2026-104286 — Fortinet FortiMail unauthenticated path traversal → arbitrary file write (CVSS 3.1: 9.8)
Path traversal combined with improper NULL-byte handling in FortiMail's Identity-Based Encryption (IBE) GUI lets an unauthenticated remote attacker write arbitrary files to the underlying filesystem via crafted HTTP/HTTPS requests, enabling full device compromise. Fortinet published advisory FG-IR-26-175 on Oct 1 confirming active exploitation; CISA added it to KEV the same day with a federal remediation deadline of Oct 4, 2026. Affected: FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9.
**Fix:** No patched build is available yet — 8.0.2, 7.6.7, and 7.4.9 are listed "upcoming"; the 7.2.x line must migrate to 7.4. Immediate workaround: disable the IBE feature and block internet access to the management interface, then hunt for signs of compromise.
Source: https://fortiguard.fortinet.com/psirt/FG-IR-26-175

## Critical CVEs (NVD, CVSS ≥ 9.0, no confirmed exploitation)

### CVE-2026-88920 — Apache WSS4J authentication bypass (CVSS 3.1: 9.8)
A flaw in the WSS4J DOM security processor lets an unauthenticated remote attacker forge authenticated SOAP messages by crafting an unsigned SAML "sender-vouches" assertion, defeating WS-Security authentication in any Java application that relies on the library. Published Sept 30, 2026; no confirmed in-the-wild exploitation yet.
**Fix:** Upgrade to WSS4J 4.0.2, 3.0.6, or 2.4.4.
Source: https://www.thehackerwire.com/vulnerability/CVE-2026-88920/

### CVE-2026-102115 & CVE-2026-102147 — Kiteworks Core password-reset bypass and stored XSS to admin takeover (CVSS 3.1: 9.8 / 9.3)
CVE-2026-102115 is a broken password-reset workflow: an unauthenticated attacker who knows a user's email address can reset that account's password — including admin accounts — without ever touching the emailed reset link. CVE-2026-102147 is a stored XSS that an unauthenticated attacker can plant to run arbitrary JavaScript inside an administrator's session, enabling creation of a rogue admin account. Both were disclosed Sept 30–Oct 1 as part of a 78-flaw Kiteworks patch batch; no confirmed exploitation yet.
**Fix:** Upgrade Kiteworks Core past 9.5.0 (and the 9.4.x line) per the vendor advisory.
Source: https://securityonline.info/kiteworks-vulnerabilities/

## General News

### MetaMask discloses infrastructure security incident, triggers $1.4B precautionary validator exit
MetaMask disclosed on Oct 1 that block rewards from several of its validators were being quietly redirected to a wallet funded through the Tornado Cash mixer. The company found no evidence of a threat to user wallets or funds — the confirmed loss is 0.36 ETH — but as a precaution it began withdrawing roughly 17,000 validators from staking, representing about $1.4 billion, with the exit expected to complete by Oct 7. MetaMask is working with partners and security advisors to resolve the issue.
Source: https://www.bleepingcomputer.com/news/security/metamask-discloses-security-incident-affecting-its-infrastructure/

### Operation KillSwitch: international law enforcement dismantles KillSec ransomware gang, alleged 16-year-old leader arrested
A 10-country operation led by Germany's Hamburg State Criminal Police Office, with Europol and Eurojust support, seized KillSec's data-leak site and five central servers, secured over 110 TB of stolen victim data, and made three arrests — including the group's alleged administrator, a 16-year-old. KillSec is linked to roughly 500 victim organizations. Action day was Sept 30, with results published Oct 1.
Source: https://securityaffairs.com/200200/cyber-crime/operation-killswitch-police-dismantle-killsec-ransomware-group.html
