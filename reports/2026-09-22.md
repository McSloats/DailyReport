## 🟠 Critical CVEs (CVSS ≥ 9.0)

**CVE-2026-90817 — REDCap Unauthenticated RCE via Survey Passthrough and Data Import**
CVSS 9.8. Affects REDCap (Vanderbilt University's widely deployed clinical/research data capture platform), versions 13.3.0+. An unauthenticated attacker who knows a valid public survey hash can reach an unintended controller route and supply a crafted file-path/stream parameter during import handling to achieve remote code execution. A working proof-of-concept and mass-check tooling were published on GitHub within the last two days; no confirmed in-the-wild exploitation yet, but public PoC substantially raises near-term risk for the many universities and hospitals running public REDCap surveys. **Fix:** upgrade to 16.0.49 LTS, 17.3.10 LTS, or 17.4.4 Standard Release.

## 🔵 Vendor Advisories

**CVE-2026-28326 — SolarWinds Access Rights Manager: Hard-Coded Key Enables Unauthenticated RCE**
CVSS 8.8. All versions of ARM 2026.2 and prior ship a hard-coded static cryptographic key (CWE-321). Any attacker with network reachability to the ARM service can use the baked-in key to forge authentication tokens and run arbitrary commands with no account or user interaction required. Published September 17; SolarWinds reports no evidence of exploitation to date. **Fix:** upgrade to Access Rights Manager 2026.2.1.
Source: https://www.hendryadrian.com/solarwinds-patches-arm-hard-coded-key-flaw-enabling-unauthenticated-rce/

**CVE-2026-93485 — WordPress "Comment2Shell": Anonymous Comment XSS Chains to Admin-Session RCE**
CVSS 7.1. A gap between how WordPress core sanitizes a comment on save versus how it reformats the comment on display lets an anonymous, unauthenticated comment carry stored XSS that fires when an admin views it — and that admin session can then be used to upload a web shell, turning a comment-form bug into full site takeover. Fixed September 17 in WordPress 7.1.1 (also patched back through 6.9.x and earlier branches). No reported exploitation, but the fix and technical write-up are both public. **Fix:** update to WordPress 7.1.1 or the corresponding patched point release for your branch.
Source: https://thehackernews.com/2026/09/wordpress-comment2shell-flaw-can-turn.html
