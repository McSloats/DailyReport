## Actively Exploited / CISA KEV

CISA added seven CVEs to its Known Exploited Vulnerabilities catalog on Sept 2, 2026 (federal remediation due Sept 5). Two additional items below are confirmed under active exploitation but not yet KEV-listed.

### CVE-2026-83548 / CVE-2026-83549 — SonicWall SMA1000 (CVSS 10.0 / 7.8)
Pre-auth SSRF in the SMA1000 Work Place interface (-83548) chained with an OS command-injection bug in the Appliance Management Console (-83549) yields unauthenticated RCE on SMA 6210/7210/8200v appliances. **Fix:** Apply SonicWall's Sept 1 hotfixes immediately.
Source: https://www.rapid7.com/blog/post/etr-critical-sonicwall-sma1000-vulnerabilities-cve-2026-83548-cve-2026-83549-exploited-in-the-wild/

### CVE-2026-49869 — Kestra OSS (CVSS 10.0)
Unauthenticated OS command injection — lets an attacker create and execute arbitrary workflows without credentials. **Fix:** Upgrade to the patched Kestra OSS release.
Source: https://www.cisa.gov/news-events/alerts/2026/09/02/cisa-adds-seven-known-exploited-vulnerabilities-catalog

### CVE-2026-82329 — JFrog Artifactory (CVSS 9.8)
Authentication bypass lets an unauthenticated attacker mint admin access tokens on self-hosted Artifactory instances. Actively exploited in the wild since Sept 1 (attackers minting admin tokens, enumerating users/credentials). **Fix:** Upgrade to 7.111.21 / 7.117.28 / 7.125.20 / 7.133.29 / 7.146.38 / 7.161.20 (per branch); rotate exposed credentials and audit logs.
Source: https://www.securityweek.com/critical-jfrog-artifactory-vulnerability-reportedly-exploited-in-the-wild/

### CVE-2026-9586 — Sangoma Switchvox (CVSS 9.3)
Unauthenticated SQL injection in the `/pa` endpoint escalating to RCE as PostgreSQL superuser. Exploitation observed since Aug 30. **Fix:** Upgrade to Switchvox SMB Edition 8.4.0.2 (build 105309) or later.
Source: https://www.helpnetsecurity.com/2026/09/02/exploitation-of-sangoma-switchvox-flaw-underway-cve-2026-9586/

### CVE-2026-32475 — Elementor Pro (WordPress) (CVSS 9.0)
Faulty multi-file upload validation (versions ≤4.2.1) lets an unauthenticated attacker drop a PHP webshell for RCE. Wordfence has blocked ~200,000 exploitation attempts since the patch. **Fix:** Update to Elementor Pro 4.2.2 (released Aug 19); scan for planted webshells if not already patched.
Source: https://www.bleepingcomputer.com/news/security/critical-elementor-pro-flaw-exploited-to-take-over-wordpress-sites/

### CVE-2026-59822 — BerriAI LiteLLM (CVSS 8.8)
MCP Streamable HTTP endpoint accepts a fabricated Authorization header via an OAuth2 passthrough fallback, granting an unauthenticated attacker an authenticated MCP session. **Fix:** Update LiteLLM to the patched release; audit MCP session logs.
Source: https://www.cisa.gov/news-events/alerts/2026/09/02/cisa-adds-seven-known-exploited-vulnerabilities-catalog

### CVE-2026-48710 — Kludex Starlette
HTTP request/response smuggling flaw in the Python ASGI framework, added to KEV Sept 2 on evidence of active exploitation. **Fix:** Upgrade Starlette to the patched version referenced in the CISA advisory.
Source: https://www.cisa.gov/news-events/alerts/2026/09/02/cisa-adds-seven-known-exploited-vulnerabilities-catalog

## Critical CVEs (NVD, CVSS ≥ 9.0, not yet confirmed exploited)

### CVE-2026-20212 — Cisco Nexus 9000 (Silicon One) (CVSS 9.8)
Ten Silicon One–based Nexus 9000 models bind a service to an unrestricted address, leaving TCP 43210/43211 reachable in the default VRF; crafted input executes as root or crashes/reloads the switch. Nexus 3000/7000, other 9000 models, and ACI mode are unaffected. Cisco PSIRT: no known malicious use as of Sept 3. **Fix:** Patches available since Sept 2; interim mitigation via iACLs or blocking TCP 43210/43211 to local addresses.
Source: https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-n9k-s1-rce-EH8dEtr

### CVE-2026-73749 — HPE ArubaOS-CX (CVSS 9.8)
Unauthenticated buffer overflow in an ArubaOS-CX daemon allows RCE with elevated privileges via crafted packets. Same bulletin covers 23 additional flaws (auth bypass, privilege escalation, DoS, stored XSS, CSRF, predictable default passwords). **Fix:** Update to AOS-CX 10.18.1002 / 10.17.1030 / 10.16.1060 / 10.13.1190 / 10.10.1181 (branch-dependent; 10.10.1181 is EOM).
Source: https://www.bleepingcomputer.com/news/security/hpe-patches-critical-arubaos-cx-remote-code-execution-flaw/
