## Actively Exploited / CISA KEV

**CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC & Gateway**
Unauthenticated RCE zero-days affecting every deployment on an affected version, including default config. Exploited in the wild before a patch existed; CISA added to KEV Sept 27. Fix: apply the fixed builds released Sept 27 (bulletin CTX697096).
Source: https://www.cisa.gov/news-events/alerts/2026/09/27/critical-zero-day-vulnerabilities-exploited-citrix-netscaler-adc-gateway

**CVE-2026-94127 — F5 BIG-IP APM (OAuth Authorization Server), CVSS 9.8**
Heap-based buffer overflow allows unauthenticated RCE on BIG-IP virtual servers with an APM access policy + OAuth profile. F5 confirmed active exploitation; KEV added Sept 22. Fix: apply the version-matched hotfix.
Source: https://thehackernews.com/2026/09/f5-patches-critical-big-ip-apm-zero-day.html

**CVE-2026-85102 / CVE-2026-93616 — Check Point Security Gateway, Spark Firewalls & Management Server, CVSS 9.8**
-85102: cert-validation bypass in VPN negotiation → unauthenticated RCE (exploited against Spark customers since Sept 12). -93616: pre-auth path traversal in Management web service (attacks observed as early as July 23, before disclosure). KEV added Sept 22, federal deadline Sept 25. Fix: apply hotfixes shipped Sept 9.
Source: https://blog.checkpoint.com/security/security-advisory-action-required-active-exploitation-of-cve-2026-85102-and-a-management-pre-authentication-vulnerability-cve-2026-93616/

**CVE-2026-87902 — WordPress Core (4.7.0–7.1.1), CVSS 9.2**
Unauthenticated LFI via `get_page_template()` resolution, converts to RCE on most real deployments. First exploitation attempt recorded 11:49 UTC Sept 22, same day as patch. KEV added Sept 25; FCEB deadline is today, Sept 28. Fix: update to 7.1.2 / 7.0.6 / 6.9.9 / 6.8.10.
Source: https://thehackernews.com/2026/09/attackers-exploit-wordpress-cve-2026.html

**CVE-2026-35273 — Oracle PeopleSoft (Environment Management Hub)**
Google/Mandiant reports ShinyHunters (UNC6240) renewed mass exploitation, now bypassing string-based WAF rules via URL-encoding in the `/PSEMHUB/` request path. Web shells deployed on dozens of systems across education, tech, healthcare, government, and more; 100+ orgs notified. Fix: install Oracle's patch (available since June 10) — WAF rules alone are insufficient.
Source: https://cloud.google.com/blog/topics/threat-intelligence/shinyhunters-renewed-mass-exploitation-campaign-targeting-oracle-peoplesoft

**CVE-2026-93952 — Arista VeloCloud Orchestrator**
Improper input validation, added to CISA KEV Sept 22 confirming in-the-wild exploitation. Fix: apply Arista's current patch; restrict management access.
Source: https://www.cisa.gov/news-events/alerts/2026/09/22/cisa-adds-four-known-exploited-vulnerabilities-catalog
