### CVE-2026-88779 — Citrix NetScaler ADC/Gateway SAML DoS
**CISA KEV** · Added Oct 11, 2026 · Exploited (zero-day)
A memory-handling flaw in NetScaler appliances configured for SAML authentication (Gateway/AAA) lets an attacker trigger a crash/denial-of-service; researchers are still assessing escalation to RCE. CISA confirmed zero-day exploitation before adding it to KEV.

### CVE-2026-96951 — Windows Shell Mark-of-the-Web Bypass
CVSS 8.8 · Exploited zero-day · Patched Oct 13, 2026 (Patch Tuesday)
A crafted file delivered via email, IM, or web download can bypass Mark of the Web, disabling downstream protections like SmartScreen and Office Protected View once opened. Microsoft confirms active exploitation; this was the most urgent fix in this month's record 1,413-CVE Patch Tuesday (~70–75 critical, 3 zero-days total).
**Fix:** Apply the October 2026 Windows cumulative update immediately.
Source: https://www.crowdstrike.com/en-us/blog/patch-tuesday-analysis-october-2026/

### CVE-2026-21589 — Atlassian Data Center Path Traversal
Exploited · Patched Oct 5, 2026 · Exploitation began Oct 7, 2026

Disclosed Oct 9, 2026 · Not yet confirmed exploited
Affects NetScaler appliances configured as SAML IdP or SP; can allow remote code execution or denial of service. Citrix has not confirmed in-the-wild exploitation yet but notes an active exploitation history for this product line this year.

Source: https://www.csoonline.com/article/4230642/citrix-warns-of-actively-exploited-netscaler-flaw-days-after-zero-day-patch-rush.html

### CVE-2026-76471 — Cisco NX-OS NX-API Heap Overflow
CVSS 9.8 · Patched Oct 7, 2026 · No known exploitation
Heap-based buffer overflow in the NX-API management interface on Nexus 3000/9000 switches (standalone mode) that can allow root code execution or a device crash. Headline bug among five critical (CVSS 9.8) NX-OS advisories published the same day. NX-API is disabled by default, limiting exposure.
**Fix:** Confirm NX-API/NGOAM/MPLS OAM/SRv6/NV Overlay feature states, restrict management-plane access, and upgrade to Cisco's fixed NX-OS release.
Source: https://www.bleepingcomputer.com/news/security/cisco-warns-of-critical-flaws-allowing-nexus-switch-takeover

## 🟡 Vendor Advisories

### CVE-2026-105445 — Docker Hub Token-Reassignment Flaw
CVSS 9.4 · Advisory posted Oct 12, 2026 · Fixed, no exploitation found
Converting a Docker Hub account into an organization reassigned personal access tokens to the new owner without revoking the old secret or requiring consent — a supply-chain risk. Docker patched within hours of the report and found no evidence of exploitation after reviewing ~304,000 pushes made with transferred tokens.
**Fix:** Already patched server-side; affected users were notified directly and transferred tokens deactivated Oct 8. No action needed otherwise.
Source: https://www.docker.com/blog/docker-hub-security-advisory-cve-2026-105445
