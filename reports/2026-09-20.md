## 🔵 Vendor Advisories

**"Click2Shell" — WordPress Core Pre-Auth RCE Chain via Theme-Preview Injection**
Disclosed Sept 18 by the pwn.ai research team. Chains three primitives — theme-preview selector injection that forces a logged-in admin's browser to silently install an attacker-chosen catalog theme, pre-activation PHP execution via the Customizer, and an unprotected AJAX installer in the Mobile Repair Zone plugin (≤2.5.4) — into full pre-authentication remote code execution against WordPress Core below 7.1.1. No formal CVSS score published for the chain as a whole; no in-the-wild exploitation reported. **Fix:** update WordPress Core to 7.1.1 (released Sept 17) and remove/update Mobile Repair Zone if installed.
Source: https://thehackernews.com/2026/09/new-wordpress-click2shell-flaw-forces.html

**"BragJack" — Malicious Browser Extension Hijacks AI Assistants Across Five Browsers**
Security researcher Gal Weizman (Forever Security) demonstrated an attack abusing Chromium's declarativeNetRequest API to hijack the built-in AI agents in Chrome, Edge, Opera Neon, Perplexity Comet, and Claude in Chrome via a technique called "Prompt Forcing," once a malicious extension is installed. Demonstrated impact includes reading local files and browsing history, taking screenshots, and forcing agents to exfiltrate data. Google assigned CVE-2026-0628 (CVSS 8.8) and fixed it in Chrome 143.0.7499.192/.193; the other four vendors have also shipped fixes. No in-the-wild attacks reported. **Fix:** update to the latest browser build; audit installed extensions and their permissions.
Source: https://www.bleepingcomputer.com/news/security/bragjack-attacks-hijack-ai-browser-agents-through-malicious-extensions/

## General News

**Attacker Hijacks Live AI Coding-Assistant Session, Spreads Shai-Hulud Worm Across ~100 Repositories**
Per a Mandiant report, an attacker compromised an active AI coding-assistant session at an unnamed SaaS provider: the assistant recommended a package the attacker had poisoned, the developer accepted it, and the attacker rode the developer's live session to install an infostealer via a poisoned PyPI package, steal GitHub OAuth tokens, and spread the Shai-Hulud npm worm across roughly 100 internal repositories, harvesting secrets and source code. Shai-Hulud doesn't rely on a software vulnerability — it assumes credentials are already sitting on disk and exfiltrates them via a malicious preinstall script. Mandiant recommends checking AI-recommended dependencies against checksums/allowlists, keeping long-lived tokens out of reach of extensions, and routing dependency installs through controlled internal registries.
Source: https://thehackernews.com/2026/09/attacker-hijacks-ai-coding-assistant.html
