## Actively Exploited / CISA KEV

### CVE-2026-75650 — Adobe Commerce/Magento "StyleSmuggler" RCE (CVSS 10.0), now patched
The unauthenticated RCE zero-day flagged in yesterday's report now has a CVE and an Adobe fix. The bug abuses Magento's template engine via a "Payment Transaction Failed Reminder" email to achieve PHP code execution; attackers used it to drop a Rust-based Linux backdoor and PHP web shells on otherwise fully-patched stores. CISA added it to KEV on September 8. **Fix:** apply Adobe's APSB26-146 hotfix (VULN-39341) for Commerce/Magento 2.4.4–2.4.9 and Commerce B2B 1.3.3–1.5.3, and rotate encryption keys.
Source: https://thehackernews.com/2026/09/adobe-patches-magento-zero-day.html

### CVE-2026-67276 + CVE-2026-86060 — MikroTik RouterOS "MikroTrick" chain
RouterOS incompletely validates an authorized SSH public key, letting an attacker who knows a username and its key's public modulus craft a substitute key that's wrongly accepted. Chained with CVE-2026-86060 (CVSS 9.2), a crafted username tricks the SSH login helper into granting full administrative privileges. Exploitation began September 2, a day before patched builds shipped; 122,500+ routers have SSH exposed. **Fix:** update to the RouterOS builds MikroTik released September 3 immediately and audit for unauthorized accounts.
Source: https://www.helpnetsecurity.com/2026/09/07/mikrotik-routeros-ssh-vulnerabilities-exploited/

### CVE-2026-81963 — Windows Update Stack link-following zero-day (CVSS 7.8)
Exploited in the wild to escalate local privileges to SYSTEM — the first exploited flaw in the Windows Update Stack. Patched in this week's Patch Tuesday; CISA added it to KEV with a September 22 deadline for federal agencies. **Fix:** install the September 2026 Windows cumulative updates.
Source: https://www.bleepingcomputer.com/news/microsoft/microsoft-september-2026-patch-tuesday-fixes-966-flaws-2-zero-days/

### CVE-2026-85880 — Windows ALPC heap overflow zero-day (CVSS 7.8)
A heap-based buffer overflow combined with use of an uninitialized resource in Windows ALPC was exploited in the wild for SYSTEM-level privilege escalation. Fixed in the same Patch Tuesday batch and added to CISA's KEV catalog. **Fix:** install the September 2026 Windows cumulative updates.
Source: https://www.bleepingcomputer.com/news/microsoft/microsoft-september-2026-patch-tuesday-fixes-966-flaws-2-zero-days/

### CVE-2026-86218 — N-able N-central (follow-up: formal KEV listing)
Covered in yesterday's report as under active exploitation; CISA formally added it to KEV on September 8 with a September 11 deadline for federal agencies. No change to remediation guidance (Hotfix 4, build 2026.3.1.14).

## Critical CVEs (NVD, CVSS ≥ 9.0, not yet confirmed exploited)

### CVE-2026-44756 "OVERPASS" — SAP Kernel buffer overflow (CVSS 10.0)
A classic buffer overflow in the SAP Kernel's Extended Passport Protocol (EPP) processing library, reachable through the Internet Communication Manager, lets an unprivileged remote attacker run arbitrary commands with administrative privileges. Onapsis counts over 10,000 internet-facing SAP systems exposed. Part of SAP's September patch day (20 vulnerabilities total). **Fix:** apply SAP Security Note #3747649 for affected KERNEL versions (7.22, 7.53, 7.54, 7.77, 7.89, 7.93, 8.04, 9.16–9.20) and Web Dispatcher immediately.
Source: https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-overpass-kernel-vulnerability/

### CVE-2026-76578 + CVE-2026-76560 — FreeIPA / 389 Directory Server admin-credential chain (CVSS 9.8 / 7.5)
FreeIPA's self-managed OTP-token ACI doesn't require authentication or restrict which attributes accompany a token entry. Chained with a 389 Directory Server flaw where an unauthenticated ("empty name") client passes an ownership check meant for logged-in users, an anonymous LDAP client can create an attacker-controlled Kerberos principal and add it to the administrators group. **Fix:** upgrade FreeIPA to 4.13.4+; until patched, restrict LDAP ports 389/636 to trusted hosts only.
Source: https://thehackernews.com/2026/09/freeipa-flaw-chain-lets-anonymous.html

### CVE-2026-12744 + CVE-2026-12745 — Ivanti Neurons for ITSM deserialization RCE (CVSS 9.8 each)
Two deserialization-of-untrusted-data bugs can be triggered by an unauthenticated attacker to execute arbitrary code on the server. Ivanti reports no evidence of pre-disclosure exploitation. Part of a broader September 8 advisory covering 10 CVEs across EPMM, Neurons for ITSM, and Sentry. **Fix:** cloud/SaaS instances were already patched August 9; on-prem customers on 2025.2–2026.1 must apply the September patches now (2026.2 on-prem ships September 21).
Source: https://securityonline.info/ivanti-neurons-itsm-rce-vulnerabilities-2026/
