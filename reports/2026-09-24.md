**CVE-2026-87902 — WordPress Core: Path Traversal Leading to Conditional RCE (CVSS 9.2)**
A path-traversal flaw in WordPress core's page-template resolution lets an attacker force the loader to include an arbitrary local PHP file (e.g. `pearcmd.php`) and write new PHP files to disk, when the active theme has a top-level directory prefixed `page-` and a reachable target file exists. WordPress shipped 7.1.2 (with backports) on September 22; Patchstack recorded probing roughly five hours later (17:44 UTC same day), and telemetry logged 68 exploitation attempts starting September 23. **Confirmed under active exploitation.** **Fix:** update to WordPress 7.1.2 or the matching backported release immediately.

Affects AEM 6.5 Forms JEE (versions up to 6.5.25). An incorrect-authorization flaw lets a remote, unauthenticated attacker execute arbitrary code with no privileges and no user interaction. No confirmed in-the-wild exploitation. **Fix:** apply Adobe's AEM Forms security update (APSB25-82).
Source: https://helpx.adobe.com/security/products/aem-forms/apsb25-82.html

**CVE-2026-80155 — Lantronix Out-of-Band Devices: Auth-Bypass via Path Truncation → RCE (CVSS 10.0)**
Affects SLC8000 (pre-9.7.0.5), EMG7500/EMG8500 (pre-9.7.0.1), and all current firmware on SLB882/SLCx-02/SLCx-03. A fixed-size `snprintf` buffer building the session-cookie file path can be truncated by a specially-sized cookie value, redirecting authentication checks to an attacker-chosen file and bypassing login — enabling config-file theft and arbitrary file upload for full RCE. These devices provide remote/out-of-band management for critical-infrastructure and data-center gear. No confirmed exploitation yet. **Fix:** update SLC8000 to 9.7.0.5+ and EMG7500/EMG8500 to 9.7.0.1+; isolate SLB882/SLCx-02/SLCx-03 management interfaces until a fix ships.
Source: https://www.securityweek.com/lantronix-device-used-in-critical-infrastructure-exposes-systems-to-remote-hacking/

**CVE-2026-7866 — RTI Connext Professional: Stack-Based Buffer Overflow (CVSS 10.0)**
