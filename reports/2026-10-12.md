## Critical CVEs (CVSS ≥ 9.0)

### CVE-2026-106126 — Tenable Identity Exposure AD Events Listener OS command injection (CVSS 9.9)
A command injection (CWE-78) in the Active Directory Events Listener component of Tenable Identity Exposure (SaaS) lets an authenticated, low-privileged attacker run arbitrary commands as SYSTEM on the Primary Domain Controller emulator (PDCe) — a near-total compromise of the monitored Active Directory environment. Published and fixed by Tenable the same day, Oct 8, via advisory TNS-2026-27. Not listed in CISA's KEV catalog and no public proof-of-concept has been reported.
**Fix:** Upgrade to Tenable Identity Exposure (TIE) SaaS version 3.126.0 or later. Tenable's advisory also calls for running `Register-TenableIOA.ps1 -Uninstall` to remove the vulnerable listener component, then reinstalling cleanly. Confirm exact steps and on-prem applicability directly against TNS-2026-27.
Source: https://cyber.gc.ca/en/alerts-advisories/tenable-security-advisory-av26-354
