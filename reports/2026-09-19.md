## 🟠 Critical CVEs (CVSS ≥ 9.0)

**CVE-2026-93603 — vm2 Sandbox Escape to Full Host RCE via Non-Strict Host Function**
CVSS 10.0 (related: CVE-2026-93605, CVE-2026-93606). Published Sept 18. When sandboxed code in the widely-used (now-deprecated) vm2 Node.js sandboxing library calls a host-provided non-strict function without a receiver, V8 substitutes the host's global object for `this`; vm2 hands that object back to the sandbox, giving untrusted script a live proxy onto `process` and full code execution on the host. Affects vm2 through 3.12.0 — used by many app-level "sandboxes," including some AI-agent execution runtimes. **Fix:** upgrade to vm2 3.12.1; if migration isn't possible, treat vm2 as unable to isolate untrusted code and move to a process- or VM-level sandbox.
Source: https://www.vulncheck.com/advisories/vm2-before-3.12.1-sandbox-escape-rce-via-non-strict-host-function

**CVE-2026-54734 — Prebid Server Java: SSRF via Unvalidated Bidder-Adapter URLs**
CVSS 10.0. Certain bidder adapters in Prebid Server Java interpolate attacker-supplied bid-request parameters directly into outbound request URLs without validating the resulting domain or path via HttpUtil. A malicious bid request can force the server to reach internal services, cloud metadata endpoints, or other sensitive network destinations (CWE-918, SSRF). Affects versions prior to 3.43.0. **Fix:** upgrade Prebid Server Java to 3.43.0 or later.
