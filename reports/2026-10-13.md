## Actively Exploited / CISA KEV

### CVE-2026-104286 — Fortinet FortiMail path traversal lets attackers write arbitrary files (CVSS 9.8)
An unauthenticated path-traversal flaw with improper NULL-byte handling in FortiMail's HTTP/HTTPS interface lets a remote attacker write arbitrary files to the underlying system. Observed intrusions include modified binaries, a malicious `ld.so.preload` entry, and tampered web server configs. Affects FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, and 7.4.0–7.4.8 (some sources extend this to 7.2.x).
**Fix:** No corrected build was available at time of reporting. Added to CISA KEV Oct 1 (federal deadline Oct 4). Apply Fortinet's workarounds immediately and inspect exposed appliances for the compromise indicators above; watch advisory FG-IR-26-175 for a patched release.
Source: https://thehackernews.com/2026/10/critical-fortimail-zero-day-flaw.html

### CVE-2026-102489 / CVE-2026-102490 — Zammad helpdesk chain used to breach DIVD (CVSS 9.4–9.8, sources conflict)
CVE-2026-102489 (session fixation, Zammad 6.3.0–6.5.4 and 7.0.0–7.1.3) lets an attacker gain code execution as the `zammad` service user; CVE-2026-102490 (improper privilege management, 1.5.0–7.1.0-alpha) then escalates that to root. The Dutch Institute for Vulnerability Disclosure (DIVD) says its own systems were breached through this chain; Zammad GmbH disputes DIVD's affected-version claims and disclosure handling, so treat the fix status as unresolved.
**Fix:** Added to CISA KEV Oct 2 (federal deadline ~Oct 5). No formal vendor advisory existed as of Oct 5 — restrict external access to Zammad instances and monitor for anomalous sessions in the meantime.
Source: https://securityaffairs.com/?p=200248

## Critical CVEs (NVD, CVSS ≥ 9.0)

### CVE-2026-63688 / CVE-2026-63692 — Dell Container Storage Modules, unauthenticated path to full storage-admin takeover (CVSS 10.0)
CVE-2026-63688 is a missing-authentication flaw in the `csm-authorization-storage` gRPC server that lets an unauthenticated remote attacker obtain admin credentials for every registered storage array. CVE-2026-63692 is a separate missing-authentication flaw in the authorization proxy/tenant service enabling a full auth bypass to admin privileges. Affects CSM deployments fronting PowerStore, PowerScale, PowerFlex, PowerMax, and Unity XT. A related flaw, CVE-2026-67269 (CVSS 9.9), lets a low-privileged attacker reach root on cluster nodes via the CSM Operator. No exploitation confirmed; no workarounds exist.
**Fix:** Upgrade Dell Container Storage Modules to v1.18.0 or later (disclosed Oct 1 as part of an 18-flaw batch).
Source: https://www.csoonline.com/article/4230923/dell-patches-18-critical-flaws-that-could-hand-attackers-the-keys-to-storage-and-kubernetes.html

### CVE-2026-106126 — Tenable Identity Exposure command injection to SYSTEM on the domain controller emulator (CVSS 9.9)
A command-injection flaw (CWE-78) in the Active Directory Events Listener of Tenable Identity Exposure (SaaS) lets an authenticated, low-privileged attacker run arbitrary commands as SYSTEM on the PDCe. No public PoC or in-the-wild exploitation reported; not on CISA KEV.
**Fix:** Upgrade to TIE SaaS 3.126.0 (advisory TNS-2026-27), then run `Register-TenableIOA.ps1 -Uninstall` and reinstall the listener — the version bump alone does not remediate existing installs.
Source: https://www.tenable.com/security/tns-2026-27

### CVE-2026-76747 — HPE Aruba AOS-S unauthenticated buffer overflow (CVSS 9.1, unverified)
An unauthenticated, remotely triggerable buffer overflow in AOS-S switch firmware can expose memory contents or cause denial of service. Dated Oct 6; no remediation published yet. Sourced only from a third-party CVE tracker — no HPE vendor advisory located, confirm before acting.
**Fix:** No fixed build published as of reporting — watch HPE's ArubaNetworking advisory library.
Source: https://app.opencve.io/cve/CVE-2026-76747
