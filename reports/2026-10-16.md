## 🔴 Actively Exploited / CISA KEV

### CVE-2026-104935 — Ivanti Connect Secure Unauthenticated RCE via Auth Bypass
CVSS 8.6 · Zero-day, exploited since Oct 1, 2026 · KEV added Oct 13, 2026
A single request with a crafted `X-DSCGI-PATH` header lets a remote, unauthenticated attacker bypass authentication on Connect Secure gateways. Volexity found the bug chained with a second, unpatched privilege-escalation flaw to gain root-level command execution on fully patched appliances (actor tracked as UTA0576).
**Fix:** Update to 25.1.1.2, 25.1.3.0/25.1.3.1, or 22.8R2.5 immediately — CISA's federal deadline is today, Oct 16, 2026.
Source: https://www.bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks

### CVE-2026-76519 — Cisco Secure Email Gateway Path Traversal to Root RCE
CVSS 9.8 · Exploited · KEV added Oct 14, 2026
A relative path-traversal flaw in Secure Email Gateway's Advanced Malware Protection scanner lets an unauthenticated attacker write files and run commands as root via a crafted email attachment. Only gateways with File Reputation enabled and Content Scanner Tools older than 25.3.0.5525 are exposed.
**Fix:** Upgrade to fixed builds 15.5.5-014 or 16.5.0-780; check Cisco's advisory for compromise indicators.
Source: https://thehackernews.com/2026/10/cisco-warns-of-active-attacks.html

### CVE-2026-0322 — Palo Alto PAN-OS Management Interface RCE
CVSS v4 8.6 · Limited exploitation confirmed · KEV added Oct 14, 2026
A code-injection flaw in the PAN-OS management interface lets an authenticated attacker with network access run arbitrary code as root. Palo Alto confirms "very limited exploitation" targeting internet-exposed management interfaces.
**Fix:** Apply the latest PAN-OS maintenance release and restrict management-interface access to trusted networks. Federal KEV deadline is Oct 17, 2026.
Source: https://securityonline.info/palo-alto-pan-os-rce-cve-2026-0322-exploited/

### CVE-2026-105133 / CVE-2026-105134 — Ahsay AhsayCBS Chained Auth Bypass + Command Injection
CVSS v4 5.5 / 9.3 · Exploited since Oct 7, 2026 · Not yet in CISA KEV
An improper-authentication bug in the backup console, chained with an OS command-injection flaw in the Replication Receiver component, gives attackers SYSTEM-level command execution. Huntress has observed at least five organizations hit with webshells and XMRig crypto-miners disguised as Edge executables. Ahsay's first patch did not fully fix either bug.
**Fix:** Apply hotfix 10.3.4.45 and reboot affected servers; restrict management-interface access and check for webshells/unrecognized services.
Source: https://www.bleepingcomputer.com/news/security/unpatched-ahsaycbs-flaws-exploited-to-deploy-webshells-mine-crypto
