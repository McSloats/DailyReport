## Actively Exploited / CISA KEV

### CVE-2026-94127 — F5 BIG-IP APM unauthenticated RCE (CVSS 9.8)
Unauthenticated attackers can send crafted network traffic to BIG-IP Access Policy Manager instances configured as an OAuth Authorization Server to achieve remote code execution. Added to CISA KEV September 22; federal remediation deadline September 25.
**Fix:** Apply F5's patch; disable the OAuth AS role on internet-facing instances if patching is delayed.
Source: https://www.helpnetsecurity.com/2026/09/23/check-point-f5-big-ip-apm-zero-days-targeted/

### CVE-2026-85102 / CVE-2026-93616 — Check Point Quantum Security Gateway & Management, pre-auth RCE + path traversal
A pre-auth RCE in Quantum Security Gateway began being probed days after its September 9 patch; a path-traversal flaw in the Management Web Service is also under active attack. Both added to KEV September 22; attackers reported hitting Check Point management servers and Spark firewalls.
**Fix:** Apply Check Point's September 9 hotfixes; restrict management-interface exposure.
Source: https://www.helpnetsecurity.com/2026/09/23/check-point-f5-big-ip-apm-zero-days-targeted/

### CVE-2026-93952 — Arista VeloCloud Orchestrator, improper input validation
Actively exploited flaw in the central management platform for Arista's SD-WAN. Added to KEV September 22; federal deadline September 25.
**Fix:** Apply Arista's patched Orchestrator release; restrict admin access to trusted networks.
Source: https://www.heise.de/en/news/Cyberattacks-on-F5-BIG-IP-Check-Point-Security-and-Arista-VeloCloud-11462663.html

### CVE-2026-76460 — Cisco Identity Services Engine, auth bypass → root RCE (CVSS 10.0)
Unauthenticated attackers can bypass ISE's web management interface via an API endpoint flaw and reach root command execution — enabling policy tampering, credential theft, log deletion, and lateral movement. Confirmed active exploitation; no workaround exists.
**Fix:** Apply Cisco's patched release for your ISE/ISE-PIC branch immediately.
Source: https://thehackernews.com/2026/09/cisco-warns-of-new-zero-day-ise-auth.html

### CVE-2026-63077 — JetBrains TeamCity, now confirmed in ransomware campaigns (CVSS 9.8)
CISA warned September 23 that ransomware gangs are exploiting this deserialization flaw (patched in July) to bypass auth and run arbitrary OS commands on TeamCity CI/CD servers. ~160 internet-exposed servers remain unpatched, down from 700 at disclosure.
**Fix:** Upgrade to 2025.11.7 / 2026.1.3 or later; rotate CI/CD credentials on any unpatched exposed server.
Source: https://www.bleepingcomputer.com/news/security/cisa-ransomware-gangs-now-exploiting-critical-teamcity-flaw/

### CVE-2026-7273 — Zyxel GS1900 Series switches, stack-based buffer overflow
