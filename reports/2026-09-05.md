## Actively Exploited / CISA KEV

CISA added CVE-2026-85046 to its Known Exploited Vulnerabilities catalog on Sept 4, 2026 (federal remediation due Sept 25). The remaining items are confirmed under active exploitation but not yet KEV-listed.

### CVE-2026-85046 — Google Chrome V8 type confusion (zero-day) (CVSS 8.8)
A type-confusion bug in Chrome's V8 engine lets a crafted web page corrupt object-type assumptions and execute arbitrary code inside the sandbox. Google confirmed an exploit existed in the wild before the patch shipped — the sixth actively exploited Chrome bug fixed this year. **Fix:** update to Chrome 152.0.7977.82/.83 (Win/macOS) or 152.0.7977.82 (Linux); Chromium-based browsers should follow with their own builds.
Source: https://www.bleepingcomputer.com/news/security/google-warns-of-new-chrome-zero-day-flaw-exploited-in-attacks/

### CVE-2026-19490 — Citrix NetScaler ADC / Gateway auth bypass (CVSS 9.3)
Unauthenticated remote attackers can bypass authentication on NetScaler instances configured as an AAA virtual server or Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy). Patched by Citrix in mid-August; a credible public PoC has now put it under active attack, per Belgium's national CERT and vulnerability-intel firm Previdian. Over 22,000 ADC and ~1,700 Gateway instances remain exposed to the internet. **Fix:** apply Citrix's August NetScaler builds immediately; review AAA/Gateway configs and SAML Action settings.
Source: https://www.bleepingcomputer.com/news/security/hackers-target-critical-citrix-netscaler-auth-bypass-in-attacks/

### CVE-2026-59310 — VMware vCenter Syslog Server directory traversal to RCE (CVSS 9.8)
A path-traversal flaw in vCenter's Syslog server gives unauthenticated network attackers code execution. A suspected China-nexus actor has compromised 361 hosts across 47 countries since early August, planting a reverse-SSH backdoor for persistence and, in some cases, deploying Babuk-derived ransomware. **Fix:** apply VMware's vCenter Server patch; hunt for the "zz-poc59310-syslog.log" artifact and outbound connections to 5.34.177.38.
Source: https://thehackernews.com/2026/08/suspected-china-nexus-actor-exploits.html

### CVE-2026-0768 — Langflow unauthenticated arbitrary Python code execution (CVSS 9.8)
Missing input validation lets an unauthenticated attacker execute arbitrary Python as root on exposed Langflow deployments. VulnCheck logged 50+ exploitation attempts within hours of disclosure, climbing to 360 by the following Monday; honeypots in Singapore, Israel, and the UK have been hit. **Fix:** patch Langflow to the fixed release; take internet-facing instances offline until updated.
Source: https://thehackernews.com/2026/09/attackers-exploit-critical-langflow-and.html

### CVE-2026-66066 — Ruby on Rails Active Storage arbitrary file read / secret leak (CVSS 9.5)
Chained with the Langflow flaw above by the same attackers: unauthenticated file read via Rails Active Storage exposes `secret_key_base`, the Rails master key, database passwords, storage keys, and API tokens — a direct path to RCE. **Fix:** update Rails; any instance exposed before patching should rotate `secret_key_base`, the master key, DB credentials, storage keys, and third-party tokens.
Source: https://thehackernews.com/2026/09/attackers-exploit-critical-langflow-and.html

## Critical CVEs (NVD, CVSS ≥ 9.0, not yet confirmed exploited)

### CVE-2026-53412 — Zoom Workplace for Windows unauthenticated account takeover (CVSS 9.8)
Improper input validation in the Zoom Workplace desktop client, VDI client, and Meeting SDK for Windows lets a network attacker take over a user's account with no credentials and no user interaction. Disclosed via Zoom's own offensive-security team in July; no known in-the-wild exploitation — flagged here as a still-worth-confirming risk for fleets that haven't yet updated. **Fix:** update Zoom Workplace to 7.0.0+, and the VDI client to 7.0.10 / 6.6.15 / 6.5.18 (branch-dependent).
Source: https://securityaffairs.com/195454/security/zoom-fixes-cve-2026-53412-a-critical-account-takeover-bug.html
