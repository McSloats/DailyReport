## Actively Exploited / CISA KEV

### CVE-2026-86218 — N-able N-central pre-auth RCE (CVSS 10.0)
A pre-authenticated remote code execution flaw in N-central, the RMM platform managed service providers use to administer client endpoints, is being actively exploited — Huntress confirmed exploitation attempts across multiple customer environments. Shadowserver counts roughly 1,500 internet-facing N-central servers, mostly in the US and Europe. **Fix:** apply Hotfix 4 (build 2026.3.1.14), released September 5, immediately on any on-premises instance still running HF3; hosted (NCOD) customers are already patched.
Source: https://www.helpnetsecurity.com/2026/09/07/n-able-n-central-hotfix-cve-2026-86218/

### "StyleSmuggler" — unpatched Magento / Adobe Commerce zero-day, unauthenticated RCE
Sansec disclosed an unauthenticated remote-code-execution zero-day being used to backdoor online stores since September 4, affecting all current Magento Open Source and Adobe Commerce versions including 2.4.9 — the first confirmed victim was fully patched with July/August updates applied. Adobe has not yet issued a CVE, advisory, or patch as of this report. **Fix:** no vendor patch available yet; apply Sansec's published detection/mitigation guidance and monitor for indicators of compromise.
Source: https://thehackernews.com/2026/09/unpatched-magento-and-adobe-commerce.html

### CVE-2026-83548 (CVSS 10.0) + CVE-2026-83549 (CVSS 7.8) — SonicWall SMA1000 SSRF/OS command injection chain
An unauthenticated SSRF in the SMA1000 Work Place interface can be chained with an OS command injection in the Appliance Management Console to reach unauthenticated remote code execution. Both are confirmed exploited in the wild and are now in CISA's KEV catalog — the third exploited SMA1000 zero-day chain since December. **Fix:** apply SonicWall's September 1 firmware update per advisory SNWLID-2026-0016 immediately.
Source: https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-actively-exploited-sma1000-zero-day-flaws/

### CVE-2026-85046 — Google Chromium V8 type confusion (added to CISA KEV September 4)
CISA added this Chromium V8 type-confusion flaw to the KEV catalog on September 4 based on evidence of active exploitation. **Fix:** update Chrome and other Chromium-based browsers to the latest released version.
Source: https://www.cisa.gov/news-events/alerts/2026/09/04/cisa-adds-one-known-exploited-vulnerability-catalog

## Vendor Advisories

### CVE-2026-13181 through CVE-2026-13184 — Telerik UI for ASP.NET AJAX RCE chain, public exploit released
Progress patched this padding-oracle-to-deserialization chain in Telerik UI for ASP.NET AJAX back in July (version 2026.2.708), but security firm TantoSec published a full working exploit and tooling on September 7, sharply raising the risk to any still-unpatched application that renders a `RadAsyncUpload` control with a custom (non-default) encryption key. **Fix:** confirm affected applications are running 2026.2.708 or later; if not, patch immediately now that a public exploit exists.
Source: https://thehackernews.com/2026/09/telerik-ui-padding-oracle-bug-chained.html

### ConnectWise ScreenConnect — worm-like malware campaign abusing guest file transfer (no CVE yet)
Researchers documented a four-stage VBScript payload spreading through rogue, modified ScreenConnect clients via the guest file-transfer feature, propagating worm-like to newly connected endpoints since August and dropping cryptominers, tunneling tools, and persistence mechanisms. ConnectWise confirmed the flaw in a September 3 advisory and says a CVE and official fix are coming within the week. **Fix:** disable file transfers for technicians in ScreenConnect sessions until a patch ships.
Source: https://www.helpnetsecurity.com/2026/09/07/connectwise-screenconnect-file-transfer-flaw/
