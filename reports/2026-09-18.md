## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-91843 — Check Point Security Management & Log Server: Unauthenticated Root RCE via Login Stack Overflow**
CVSS 9.8. A stack overflow in the pre-authentication login handler is triggered by a request carrying an excessively long username, letting an unauthenticated attacker on the Trusted Clients network execute arbitrary code as root. Affects Security Management Server, Multi-Domain Security Management Server, Log Server, and Multi-Domain Log Server; R82.20 is affected on all versions with no Jumbo Hotfix protection yet. Check Point disclosed it Sept 16; no in-the-wild exploitation reported, but roughly 3,800 internet-exposed management servers were identified by researchers. **Fix:** apply the urgent LivePatch per Check Point sk1000155 (customers with automatic updates are already protected); restrict Trusted Clients to known internal IPs as an interim mitigation.
Source: https://thehackernews.com/2026/09/critical-check-point-management-server.html

**CVE-2026-77179 — Docker Sandboxes (macOS): VM Escape to Arbitrary Host File Read/Write**
CVSS 9.4. The virtio-fs host server used by Docker Sandboxes on macOS improperly follows symlinks when reopening an unlinked file from a stored path (CWE-59); a malicious guest can replace a parent directory with a symlink to escape the shared workspace and read or modify arbitrary host files with the privileges of the account running the VM, potentially reaching host code execution. Affects versions 0.28.0 up to but not including 0.42.0; fixed Sept 7. A related high-severity flaw (CVE-2026-79994, CVSS 8.7) was patched in the same release. **Fix:** update Docker Desktop/Sandboxes to 0.42.0 or later.
Source: https://thehackernews.com/2026/09/critical-docker-sandboxes-flaw-lets.html

**CVE-2026-81642 — Unbound DNS Resolver: DNSSEC Validator Heap Overflow, RCE via Malicious Zone**
CVSS 9.1. When Unbound's validator digests a DNSKEY record whose owner name contains a compression pointer into the record's own data, the digest buffer is misdirected, letting an attacker who controls a queried zone overwrite memory and potentially execute arbitrary code on the resolver — no privileges or user interaction needed. Affects every release before 1.26.1. NLnet Labs shipped 1.26.1 fixing this bug plus eight others the same day; CISA marked exploitation status "none." **Fix:** upgrade Unbound to 1.26.1 or later.
Source: https://thehackernews.com/2026/09/critical-unbound-dnssec-validator-flaw.html

**Gyazo Breach Exposes 23.62 Million User Records and 490 Million Image Metadata Records**

**China-Aligned FamousSparrow Deploys New SparroWocky Backdoor via Exposed Exchange Servers**
The FamousSparrow cyberespionage group is exploiting publicly reachable Microsoft Exchange servers to deploy a new modular C-language backdoor, SparroWocky, replacing its earlier SparrowDoor implant. The campaign has concentrated on government networks across Latin America since mid-2025 — including Argentina, Ecuador, Guatemala, Honduras, Panama, Peru, Puerto Rico, and Venezuela — using a three-stage loader and TLS/RC4-encrypted command traffic to evade detection.
