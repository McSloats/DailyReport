## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-72982 — Windows Netlogon: Buffer Overflow RCE**
CVSS 9.8. Stack-based buffer overflow in the Netlogon RPC interface (domain-logon requests, secure-channel negotiation) lets an unauthenticated attacker execute code via one crafted packet, no user interaction. Netlogon runs by design on every AD domain controller and can't be disabled. Patched in the Sept 8 Patch Tuesday cumulative updates; no public exploitation reported yet, but the target makes it a same-week priority.
Source: https://www.securityweek.com/critical-windows-netlogon-vulnerability-in-attackers-crosshairs/

**CVE-2026-57967 — Apache ActiveMQ Artemis: Session Hijack**
CVSS 9.8. Missing authentication check (CWE-306) in CORE protocol SESSION_REATTACH handling lets an unauthenticated attacker hijack an existing broker session outright, inheriting the original client's privileges. Affects Artemis 2.50.0–2.56.0 and legacy ActiveMQ Artemis 1.0.0–2.44.0. Fixed in 2.57.0; no known exploitation yet, but brokers are often internet-facing in integration environments.
Source: https://radar.offseq.com/threat/cve-2026-57967-cwe-306-missing-authentication-for-critical-function-in-apache-software-foundation-ca7a2189b4bd3fd3

**ShieldCrash — Microsoft Defender privilege-escalation bypass (no CVE yet)**
A public PoC from researcher "Nightmare Eclipse" abuses Defender's Malware Protection Engine to read arbitrary files as SYSTEM on fully patched Windows 10/11/Server systems. It bypasses Microsoft's fix for the earlier ShieldBreak flaw (CVE-2026-69414), itself a bypass of June's RoguePlanet bug — round three in an ongoing dispute between the researcher and Microsoft over bug-bounty practices. As of Sept 11, no CVE, CVSS score, or patch. **Mitigation:** keep Defender/Windows updated, keep real-time protection and Tamper Protection on, watch for unsigned DLLs or unusual processes touching Defender's scan paths.
