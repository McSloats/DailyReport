## Actively Exploited / CISA KEV

### CVE-2026-88779 — Citrix NetScaler ADC/Gateway SAML memory-overflow DoS (CVSS 8.7)
A memory-overflow flaw in the SAML service-provider/identity-provider processing path on NetScaler ADC and Gateway lets an attacker with network access to a SAML-configured appliance send crafted traffic that crashes authentication services, disrupting SSO and remote access. Citrix has observed targeted attacks against unpatched appliances. CISA added it to KEV on Oct 4, with a federal remediation deadline of Oct 7 — the third exploited NetScaler zero-day inside a two-week stretch.
**Fix:** Upgrade to NetScaler 14.1-73.41+, 13.1-64.28+, or the corresponding FIPS builds (14.1-73.41 FIPS / 13.1-37.282+).
Source: https://www.bleepingcomputer.com/news/security/citrix-patches-netscaler-saml-zero-day-exploited-in-attacks/

## Critical CVEs (NVD, CVSS ≥ 9.0)

### CVE-2026-90970 — GitLab AI Gateway sandbox escape to RCE (CVSS 9.9)
An authenticated user with Duo Agent Platform access can craft a flow configuration that escapes the prompt-template sandbox in GitLab's AI Gateway, leading to arbitrary command execution on the self-hosted gateway host. Affects self-hosted AI Gateway 18.1.6 up to the fixed builds; GitLab's own hosted AI Gateway is unaffected. CISA's assessment on Oct 2 lists no confirmed exploitation yet.
**Fix:** Upgrade self-hosted AI Gateway to 19.2.4, 19.3.2, or 19.4.1.
Source: https://thehackernews.com/2026/10/gitlab-patches-critical-self-hosted-ai.html

### CVE-2026-63688 / CVE-2026-63692 — Dell Container Storage Modules missing authentication (CVSS 10.0 each)
Two maximum-severity flaws in Dell CSM: CVE-2026-63688 lets an unauthenticated attacker query the csm-authorization-storage gRPC server to obtain backend admin credentials for every registered storage array, and CVE-2026-63692 lets an unauthenticated network attacker bypass the authorization proxy/tenant service entirely to reach admin-level privileges. The same Oct 1 bulletin also carries CVE-2026-67269 (CVSS 9.9) and CVE-2026-54472 / CVE-2026-61421 (CVSS 9.8), covering privilege escalation and hard-coded credentials. Dell reports no active exploitation or public PoC so far.
**Fix:** Upgrade Dell Container Storage Modules to 1.18.0 or later.
Source: https://thehackernews.com/2026/10/dell-csm-flaws-enable-unauthenticated.html
