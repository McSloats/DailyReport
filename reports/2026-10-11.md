## Actively Exploited / CISA KEV

### Five legacy CVEs added to CISA KEV after China-linked Flax Typhoon exploitation; federal deadline is today (Oct 11)
CISA added five older vulnerabilities to its Known Exploited Vulnerabilities catalog on Oct 8 after confirming in-the-wild abuse by the China-linked actor Flax Typhoon: **CVE-2015-3306** (ProFTPD improper access control, CVSS 10.0, arbitrary file read/write), **CVE-2021-3199** (ONLYOFFICE Docs path traversal, CVSS 9.8, can lead to RCE when JWT is enabled), **CVE-2016-3081** (Apache Struts command injection via Dynamic Method Invocation, CVSS 8.1), **CVE-2015-5477** (ISC BIND reachable assertion, CVSS 7.5, DoS), and **CVE-2023-22894** (Strapi cleartext storage of sensitive data, CVSS 7.2, requires existing admin-panel access). The additions coincide with a joint advisory from seven governments (Australia, Canada, Japan, New Zealand, Spain, the UK, and the US) on operations enabled by China-based Integrity Technology Group (US-sanctioned since January 2025), which reportedly used eight vulnerabilities including these five for initial access and data theft. Federal civilian agencies must patch or remove the affected software by **October 11, 2026** — today.
**Fix:** Patch or decommission any internet-facing ProFTPD, ONLYOFFICE Docs, Apache Struts, ISC BIND, or Strapi instances still running the affected versions immediately; these are old, well-documented bugs with long-available fixes, so exposure likely indicates unpatched legacy systems. Disable unused internet-facing services, segment networks, and monitor for unusual outbound traffic per the joint advisory's guidance.
