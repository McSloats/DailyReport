## Actively Exploited / CISA KEV

- **CVE-2023-49105** (CVSS 9.8) — ownCloud WebDAV authentication bypass, plus **CVE-2026-53362** (Linux Kernel IPv6 out-of-bounds write) and **CVE-2026-66384** (JFrog Artifactory path traversal). CISA added all three to the KEV catalog on 27 Aug. The ownCloud flaw (a 2023 bug affecting core 10.6.0–10.13.0) is tied to a Chinese-speaking threat actor's breach of a Philippine nuclear research body — an exposed staging server showed ~176 files (372MB) exfiltrated, including nuclear-material account records, reactor core component data, and credential stores (BitLocker keys, KeePass/AxCrypt files). **Fix:** update ownCloud core to 10.13.1+; federal deadline for ownCloud/Linux kernel was 30 Aug, JFrog Artifactory is due 10 Sep — private orgs should treat these as equally urgent.
  Source: https://thehackernews.com/2026/08/snowflake-github-actions-flaw-lets.html
- **PaperCut NG/MF follow-up** — Huntress reports servers are being actively probed and roughly 47% of the ~2,500 tracked installations still run v23 or older, for which no patch exists (only v24–26 got the emergency fixes covered in prior editions). **Fix:** upgrade off unsupported v23-and-earlier branches entirely; there is no patch path for them.
  Source: https://securityaffairs.com/198107/uncategorized/hackers-are-probing-papercut-servers-and-47-still-have-no-patch.html

## Critical CVEs (NVD, 9.0+)

- **Five critical WordPress plugin/theme flaws**, headlined by **CVE-2026-82222** (GiveWP donation plugin, CVSS 10.0) — an unauthenticated PHP-object-injection chain (unsafe deserialization + gadget chain in bundled libraries) enabling arbitrary command execution on sites with one published donation form and an active payment gateway; 100,000+ installs affected, patched in GiveWP 4.16.7.2. Also disclosed: **CVE-2026-76581** (WPMU DEV Dashboard, CVSS 9.8, SSO auth bypass to admin takeover), **CVE-2026-18431** (Avada theme, CVSS 9.8, arbitrary file write → RCE), **CVE-2026-19598** (Pods plugin, CVSS 9.8, privilege escalation to admin), **CVE-2026-19632** (TranslatePress, CVSS 9.8, exposed password-reset tokens). No confirmed in-the-wild exploitation yet for any of the five. **Fix:** update GiveWP to 4.16.7.2+; check WPMU DEV Dashboard, Avada, Pods, and TranslatePress for vendor patches and apply immediately.
  Source: https://thehackernews.com/2026/08/five-critical-wordpress-plugin-and.html

## General News

- **TerminalFix — ClickFix variant deploys reverse-tunnel backdoor** — Microsoft Threat Intelligence detailed a new social-engineering campaign using fake Cloudflare CAPTCHA pages to trick victims into pasting PowerShell into Windows Terminal (rather than the Run dialog used by earlier ClickFix waves). The multi-stage chain combines DLL sideloading, steganographic payload extraction, Active Directory recon, and a custom reverse-tunnel implant that gives attackers persistent network-level proxy access into the victim's internal network. **Guidance:** block/alert on PowerShell launched from Terminal via clipboard paste following a CAPTCHA-style prompt; user awareness training should specifically cover this Terminal-based variant, not just the Run-dialog version.
  Source: https://thehackernews.com/2026/08/terminalfix-uses-fake-cloudflare.html
- **Manchester Airports Group breach — FulcrumSec claims 86GB stolen** — Extortion group FulcrumSec told BleepingComputer it exfiltrated ~86GB of data after finding API credentials exposed in client-side JavaScript. MAG (Manchester, London Stansted, East Midlands airports) disclosed the breach on 27 Aug and says it affects roughly 8.7 million customers, primarily car park, lounge, Fast Track booking, and Wi-Fi sign-up data. **Guidance:** audit client-side JS bundles and mobile app code for hardcoded/exposed API keys — a recurring root cause in 2026 extortion cases.
  Source: https://www.bleepingcomputer.com/news/security/fulcrumsec-claims-manchester-airports-hack-theft-of-86-gb-of-data/
