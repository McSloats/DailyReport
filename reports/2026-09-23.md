**CVE-2026-93952 — Arista VeloCloud Orchestrator: Unauthenticated Access to Privileged Functions (CVSS 10.0)**
Affects on-premises VeloCloud Orchestrator (VCO) deployments using certificate-based Edge-to-VCO authentication (Certificate Acquire / Certificate Required modes). A remote attacker with no login credentials but network access to the VCO web interface, plus the public half of an Edge device's authentication certificate, can reach privileged internal functionality and compromise the orchestrator — and, through it, the Edge devices it manages. Arista confirms active exploitation. **Fix:** patched releases are available now on the 5.2 and 6.4 trains; fixes for the 6.1 and 7.0 trains were not yet available as of September 22 — apply Arista's documented mitigations on those trains in the meantime.
Source: https://thehackernews.com/2026/09/new-cvss-100-velocloud-orchestrator.html

**CVE-2026-94127 — F5 BIG-IP APM: Heap Overflow Enables Unauthenticated RCE on OAuth-Enabled Virtual Servers (CVSS 9.8)**
Affects BIG-IP APM virtual servers that combine an APM access policy with an OAuth profile — the OAuth handling code writes attacker-controlled data into a heap buffer without validating its size, corrupting adjacent memory on the Traffic Management Microkernel (TMM) data plane and allowing unauthenticated remote code execution. Confirmed under active exploitation; added to CISA KEV September 22. **Fix:** apply F5's hotfix, or use the emergency iRule F5 published for systems that cannot be patched immediately.
Source: https://my.f5.com/manage/s/article/K000162605

**CVE-2026-85102 & CVE-2026-93616 — Check Point Security Gateway / Management Server: Pre-Auth RCE Pair (CVSS 9.8 each)**
CVE-2026-85102 is an improper VPN-certificate trust validation flaw in Security Gateway: the gateway fails to properly validate a peer's certificate during VPN negotiation, letting an unauthenticated attacker reach code execution. Check Point shipped a fix September 9, but exploitation attempts against Check Point Spark customers have been observed globally since mid-September. CVE-2026-93616 is a separate pre-auth path-traversal flaw in the Management Server web service that lets an unauthenticated attacker upload and execute an arbitrary script; Check Point fixed it September 22, the same day both were added to CISA KEV. **Fix:** apply Check Point's September 9 (Security Gateway) and September 22 (Management Server) updates immediately.
Source: https://blog.checkpoint.com/security/security-advisory-action-required-active-exploitation-of-cve-2026-85102-and-a-management-pre-authentication-vulnerability-cve-2026-93616

**Microsoft Takes Down "EvilTokens" AI-Powered Phishing-as-a-Service Operation**
Microsoft's Digital Crimes Unit, working with Cloudflare, Coinbase, OpenAI, Health-ISAC, and others, disrupted EvilTokens — a phishing-as-a-service platform that abused the OAuth 2.0 device-authorization flow to hijack Microsoft 365 sessions without stealing passwords. The service used AI to customize lures and triage stolen inboxes, compromising over 12,000 mailboxes across 10,000+ organizations. Microsoft seized 50 sites and disabled 150+ domains under a U.S. federal court order; UK police arrested two men (ages 32 and 38) on September 11 in connection with the operation.
Source: https://www.microsoft.com/en-us/security/blog/2026/09/22/unmasking-eviltokens-getting-to-the-root-of-device-code-phishing/

**"BigDiskBuster" Zero-Day PoC Can Silently Block Windows Defender Updates**
A former Microsoft Security Response Center researcher published a proof-of-concept tool that fills all remaining free disk space whenever Windows Defender attempts a platform or signature update, causing the update to fail while Defender keeps running with increasingly stale detection content. There is no CVE, no patch, and no Microsoft advisory; the claimed behavior has not yet been independently verified by outside researchers.
