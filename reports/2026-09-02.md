## Actively Exploited / CISA KEV

### CVE-2026-82329 — JFrog Artifactory Authentication Bypass (CVSS 9.8) — Exploited
An authentication weakness in default configurations lets an unauthenticated, network-adjacent attacker mint administrator tokens, granting full control over repositories, users, permissions, and build artifacts. JFrog disclosed the flaw Aug 28; attackers began weaponizing it Sept 1 to enumerate users, groups, and federated access topologies.
**Fix:** Update to Artifactory 7.161.20+; audit for unexpected admin tokens issued since Aug 28.
Source: https://thehackernews.com/2026/09/attackers-exploit-critical-jfrog.html

### CVE-2026-0768 — Langflow Unauthenticated Code Injection (CVSS 9.8) — Exploited
Missing validation on the custom-component code validator lets an unauthenticated attacker execute arbitrary Python as root. Active exploitation ongoing since disclosure as a zero-day; VulnCheck reports credential harvesting and reconnaissance against exposed instances.
**Fix:** Patch beyond Langflow 1.4.2; never expose the API/UI directly to the internet without authentication in front of it.
Source: https://www.bleepingcomputer.com/news/security/critical-langflow-flaw-exploited-to-steal-openai-and-aws-keys/

### CVE-2026-66066 — Ruby on Rails "KindaRails2Shell" Active Storage RCE (CVSS 9.5) — Exploited
Apps using libvips for image-variant processing with untrusted uploads are vulnerable to file read and RCE. Rails patched July 29, but VulnCheck found the fix leaves a Marshal deserialization gadget reachable with a valid signature. Over 7,000 vulnerable instances found directly reachable; credential-harvesting campaigns underway as of Sept 1.
**Fix:** Apply the Rails security patch and rotate `secret_key_base` plus any cloud/DB credentials that may have been readable.
Source: https://thehackernews.com/2026/09/attackers-exploit-critical-langflow-and.html

### CVE-2026-82078 / CVE-2026-81578 — PaperCut NG/MF Chained Access-Control Bypass to RCE (CVSS 9.4 / 8.8) — CISA KEV, Exploited
Two zero-days disclosed Aug 27: an access-control flaw in the admin web interface and unsafe dynamic class loading in database connection utilities. Chained, an unauthenticated attacker can reach RCE. PaperCut confirmed customer incidents; both CVEs are on CISA's KEV list.
**Fix:** Apply PaperCut's emergency patch for all NG/MF versions.
Source: https://thehackernews.com/2026/08/attackers-chain-two-papercut-flaws-to.html

### CVE-2026-64849 — MLflow Unauthenticated SSRF to Cloud Credential Theft (CVSS 9.3) — CISA KEV, Exploited
A DNS-rebinding SSRF bypass in MLflow's outbound webhook delivery lets an unauthenticated attacker reach internal cloud metadata endpoints and pull live AWS/GCP/Azure credentials. Mass scanning began within hours of the CVE's Aug 17 assignment. **CISA's federal remediation deadline is today, Sept 2, 2026.**
**Fix:** Upgrade to MLflow 3.15.0+; block Tracking Server egress to cloud metadata IPs as a compensating control.
Source: https://www.bleepingcomputer.com/news/security/cisa-warns-of-hackers-exploiting-critical-mlflow-vulnerability/

### CVE-2026-59310 — VMware vCenter Syslog Server Directory Traversal RCE (Critical) — Exploited
An unauthenticated, network-reachable directory-traversal flaw in vCenter's Syslog server allows arbitrary code execution. Broadcom disclosed/patched it July 29; exploitation compromised 361+ IPs across 47 countries, deploying a reverse-SSH tool for persistence. No workaround available.
**Fix:** Apply Broadcom's emergency vCenter update immediately; hunt for unexpected cron jobs and reverse_ssh artifacts.
Source: https://www.bleepingcomputer.com/news/security/critical-vmware-vcenter-rce-flaw-exploited-for-reverse-ssh-access/
