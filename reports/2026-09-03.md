# Daily Cybersecurity Report — 2026-09-03

Window covered: ~last 48 hours (Sep 1 – Sep 3, 2026)

## Actively Exploited / CISA KEV

CISA added seven CVEs to its Known Exploited Vulnerabilities catalog on Sept 2. The JFrog Artifactory bug (CVE-2026-82329) was one of them and was already covered in yesterday's brief; the six below are newly reported.

### CVE-2026-83548 / CVE-2026-83549 — SonicWall SMA1000 Zero-Day SSRF Chained to OS Command Injection (CVSS 10.0 / 7.8) — CISA KEV, Exploited
An unauthenticated SSRF flaw in the SMA1000 Work Place interface (83548) can be chained with an OS command injection bug in the Appliance Management Console (83549) for unauthenticated RCE. SonicWall disclosed both as actively exploited zero-days on Sept 1; affects SMA1000 6210/7210/8200v hardware. **CISA's federal remediation deadline is Sept 5, 2026.**
**Fix:** Apply SonicWall's Sept 1 hotfix immediately; restrict Work Place/AMC exposure to trusted networks and review for indicators of compromise.
Source: https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-actively-exploited-sma1000-zero-day-flaws/

### CVE-2026-49869 — Kestra OSS Unauthenticated OS Command Injection (CVSS 10.0) — CISA KEV, Exploited
The open-source workflow-orchestration platform's authentication filter matches routes with `endsWith` instead of an exact match, letting an unauthenticated attacker reach the `/configs` path, create arbitrary flows, and execute OS commands with no credentials at all.
**Fix:** Upgrade to the patched Kestra OSS release; don't expose the API/UI to the internet without an authenticating proxy in front of it.
Source: https://thehackernews.com/2026/09/cisa-adds-seven-exploited-flaws-as.html

### CVE-2026-9586 — Sangoma Switchvox Unauthenticated SQL Injection to RCE (CVSS 9.3) — CISA KEV, Exploited
The phone-provisioning `/pa` endpoint concatenates the user-supplied `PhoneIP` parameter straight into a PostgreSQL query with no sanitization, letting a remote unauthenticated attacker run arbitrary SQL and escalate to RCE. Horizon3.ai has observed valid exploitation attempts since Aug 30, deploying reverse shells; roughly 4,000 internet-exposed instances exist, most in the US.
**Fix:** Upgrade to Switchvox SMB Edition 8.4.0.2 or later.
Source: https://www.bleepingcomputer.com/news/security/hackers-exploit-sangoma-switchvox-flaw-to-deploy-reverse-shells/

### CVE-2026-59822 — BerriAI LiteLLM MCP Endpoint Authentication Bypass (CVSS 8.8) — CISA KEV, Exploited
LiteLLM's Model Context Protocol Streamable HTTP endpoint falls back to accepting empty credentials after a failed API-key check, letting an attacker establish an authenticated MCP session using an arbitrary bearer token. **CISA's federal deadline is Sept 16, 2026.**
**Fix:** Update to the patched LiteLLM release; audit MCP session logs for sessions authenticated with non-issued tokens.
Source: https://thehackernews.com/2026/09/cisa-adds-seven-exploited-flaws-as.html

### CVE-2026-48710 — Kludex Starlette HTTP Request/Response Smuggling (CVSS 6.5) — CISA KEV, Exploited
The Python ASGI framework mishandles malformed request paths, letting an attacker inject content into the host portion that gets prepended to the reconstructed URL path — enabling smuggling and, in apps that authorize by reconstructed path, authentication bypass. Lower severity than the rest of this batch, but confirmed exploited and added to KEV alongside it. **CISA's federal deadline is Sept 16, 2026.**
**Fix:** Upgrade the Starlette dependency to the patched version; don't rely solely on reconstructed-path checks for authorization.
Source: https://thehackernews.com/2026/09/cisa-adds-seven-exploited-flaws-as.html
