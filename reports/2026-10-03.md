## Actively Exploited / CISA KEV

### CVE-2026-102489 & CVE-2026-102490 — Zammad session-hijack-to-RCE chain with root privilege escalation (CVSS 9.4)
CVE-2026-102489 is a session-fixation flaw that lets a remote attacker hijack a Zammad user's session and achieve code execution as the local `zammad` service account; CVE-2026-102490 is a local privilege-escalation bug that lets that same account jump to root. Chained together the full takeover runs in seconds. CISA added both to KEV on Oct 2 following a confirmed real-world intrusion: the Dutch Institute for Vulnerability Disclosure (DIVD) was breached on Sept 21 by what researchers describe as an autonomous, AI-driven attack workflow that discovered and chained the pair on its own. Affected: Zammad 1.5.0 through 7.1.0-alpha (CVE-2026-102489 specifically 6.3.0–6.5.4).
**Fix:** Upgrade to Zammad 7.2.0 or later immediately; also audit for signs of compromise (unexpected sessions, new local accounts, outbound connections from the Zammad host).
Source: https://securityaffairs.com/200248/security/u-s-cisa-adds-zammad-gmbh-zammad-flaws-to-its-known-exploited-vulnerabilities-catalog.html

### CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC/Gateway pre-auth remote code execution (CVSS 9.5)
A pair of pre-authentication RCE zero-days in NetScaler ADC and NetScaler Gateway, exploitable via improper input validation with no special configuration required — vulnerable appliances are exposed even in default deployments. Citrix patched both on Sept 27 (bulletin CTX697096) after attackers were already exploiting them to drop web shells and steal configuration data; working proof-of-concept exploit code has since been published, raising the risk for any appliance still unpatched.
**Fix:** Upgrade to NetScaler ADC/Gateway 14.1-73.37 or 13.1-64.23 (FIPS/NDcPP: 14.1-73.37 FIPS or 13.1.37.279). Treat any internet-facing appliance patched after Sept 27 as potentially already compromised and hunt for web shells.
Source: https://www.cyberkendra.com/2026/09/cve-2026-88771-netscaler-zero-days-exploited.html

## Critical CVEs (NVD, CVSS ≥ 9.0, no confirmed exploitation)

### CVE-2026-63688 & CVE-2026-63692 — Dell Container Storage Modules missing authentication, plus CVE-2026-67269 (CVSS 10.0 / 10.0 / 9.9)
Two maximum-severity flaws in Dell CSM, which integrates Dell enterprise storage arrays with Kubernetes: CVE-2026-63688 lets an unauthenticated attacker query the csm-authorization-storage gRPC server to steal admin credentials for every registered storage array, and CVE-2026-63692 lets an unauthenticated network attacker bypass the authorization proxy/tenant service entirely to gain admin-level privileges. A related flaw, CVE-2026-67269 (CVSS 9.9), lets a low-privilege attacker escalate to root on cluster nodes. Dell says no workaround exists.
**Fix:** Upgrade Dell Container Storage Modules to 1.18.0 or later immediately; versions before 1.17.0 are vulnerable and there is no mitigation short of patching.
Source: https://thehackernews.com/2026/10/dell-csm-flaws-enable-unauthenticated.html

### CVE-2026-90970 — GitLab AI Gateway prompt-template sandbox escape to command execution (CVSS 9.9)
An authenticated Duo Agent Platform user can escape the prompt-template sandbox through a crafted flow configuration and execute arbitrary commands on a self-hosted GitLab AI Gateway. Only organizations running their own AI Gateway (its own Docker image or Helm chart, separate from core GitLab) are affected; GitLab.com's hosted gateway is not.
**Fix:** Upgrade self-hosted AI Gateway to 19.2.4, 19.3.2, or 19.4.1 (whichever matches your current branch).
Source: https://www.strix.ai/cve/CVE-2026-90970

## General News

### China-linked Warlock ransomware hits water utility, telecom, government, and university via on-prem SharePoint flaws
The China-nexus group behind Warlock ransomware (tracked as Storm-2603/Longlegs) continues exploiting on-premises Microsoft SharePoint Server vulnerabilities — building on the 2025 "ToolShell" chain plus several newer 2026 CVEs — for initial access. Over the past two months it has hit at least four organizations across Europe, Africa, and Latin America, including a water utility, a telecom provider, a regional government body, and a university, in one case disabling security tooling on 40 systems before deploying ransomware on 33 of them.
Source: https://www.securityweek.com/warlock-expands-sharepoint-exploitation-in-critical-infrastructure-attacks/

### ShinyHunters escalates after Dutch arrest: FBI site breached, Cl0p extorted
Days after Dutch police arrested an alleged member of the ShinyHunters collective (Sept 15–29), remaining members escalated rather than retreated — breaching an FBI web property and exposing Social Security numbers and personal data on over 5,000 officials, and separately attempting to extort the rival Russian ransomware group Cl0p. The FBI says ShinyHunters and its affiliates have breached 140+ organizations and collected roughly $70 million in extortion payments since last year.
Source: https://www.bleepingcomputer.com/news/security/fbi-tells-shinyhunters-members-to-turn-themselves-in-after-recent-arrest/
