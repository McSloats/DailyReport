## Actively Exploited / CISA KEV

### CVE-2026-21589 — Atlassian Data Center unauthenticated arbitrary file read (CVSS 9.3), now under active mass exploitation
Disclosed Oct 5 across eight self-hosted Atlassian Data Center products (Confluence, Jira Software, Jira Service Management, Bitbucket, Bamboo, Crowd, Crucible, Fisheye); Cloud instances were already patched. Within hours of a public technical write-up, honeypot operator Previdian recorded roughly 158 exploitation attempts from 26 attacker IPs across 8 countries — mostly fingerprinting and reconnaissance so far. watchTowr's follow-up research found Crowd-integrated deployments store plaintext application credentials (`crowd.properties`) that could let an attacker escalate to Jira admin access. VulnCheck added the CVE to its own KEV list on Oct 7; it was not yet in CISA's official KEV catalog as of this writing. Atlassian says it cannot determine whether individual customer instances were already compromised before patching.
**Fix:** Patch self-hosted Data Center instances immediately to the fixed versions in Atlassian's advisory (e.g., Confluence Data Center 9.2.26 / 10.2.19); review access logs for the activity patterns above; Cloud customers are unaffected.
Source: https://www.bleepingcomputer.com/news/security/hackers-exploit-critical-atlassian-flaw-after-public-poc-release/

### CVE-2026-105134 — AhsayCBS Replication Receiver unauthenticated command injection, actively exploited since Oct 7
Disclosed Oct 4: an OS command injection in AhsayCBS's Replication Receiver component, reachable by manipulating the 'random' parameter with no authentication needed, affecting versions up to 10.3.2. A public proof-of-concept exploit has circulated, lowering the bar for attackers. Huntress began observing in-the-wild remote code execution starting Oct 7 and had identified five targeted organizations as of Oct 8. Post-exploitation activity includes reconnaissance, webshells, and an XMRig cryptominer disguised as Microsoft Edge.
**Fix:** Upgrade to AhsayCBS 10.3.4 (unaffected). If an immediate update isn't possible, block access to the `/rps/api/json/UpdateReceivers.do` endpoint at the WAF or firewall as an interim mitigation.
Source: https://www.huntress.com/blog/ahsaycbs-flaws-exploit
