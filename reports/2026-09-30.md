## Actively Exploited / CISA KEV

### CVE-2026-86950 — Apple CoreGraphics out-of-bounds write (iOS/iPadOS/macOS)
Processing a maliciously crafted file can trigger an out-of-bounds write in CoreGraphics, leading to arbitrary code execution. Apple says it was exploited in an "extremely sophisticated attack" against specific targeted individuals; discovered and reported by Meta's Product Security team. Added to CISA KEV Sept 29; federal deadline Oct 2, 2026.
**Fix:** Update to iOS/iPadOS 26.7.1, macOS Sequoia 15.8.1, or macOS Tahoe 26.7.1.
Source: https://www.cisa.gov/news-events/alerts/2026/09/29/cisa-adds-one-known-exploited-vulnerability-catalog

### CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC & Gateway RCE (CVSS 4.0: 9.5)
Paired zero-days; CVE-2026-88772 is a memory corruption bug reachable when DTLS is enabled (default on VPN virtual servers). Citrix and CISA confirm active exploitation worldwide on unmitigated appliances, with attackers deploying web shells and tunneling malware to gain root access, steal credentials, and move laterally. Patched Sept 27 via bulletin CTX697096; federal deadline was Sept 30.
**Fix:** Upgrade to 14.1-73.37 or 13.1-64.23 (or later) immediately.
Source: https://www.rapid7.com/blog/post/etr-zero-day-exploitation-of-citrix-netscaler-adc-and-gateway-cve-2026-88771-and-cve-2026-88772/

### CVE-2026-87902 — WordPress Core unauthenticated LFI → RCE (CVSS 4.0: 9.2)
Flaw in WordPress page-template resolution lets an unauthenticated attacker manipulate the template value so `get_page_template()` includes an arbitrary readable PHP file outside the active theme's directory — no login or vulnerable plugin required. Affects WordPress 4.7.0–7.1.1. Scanning for vulnerable sites began within 5 hours of the fix shipping. Added to CISA KEV Sept 25.
**Fix:** Update to WordPress 7.1.2 (fix backported to all branches back to 4.7).
Source: https://www.bleepingcomputer.com/news/security/hackers-start-exploiting-critical-wordpress-flaw-for-code-execution/

### CVE-2026-65660 — Microsoft SharePoint Server code injection RCE (CVSS 3.1: 8.8)
An authenticated attacker with low-level access can execute arbitrary code via improper control of code generation (CWE-94). Patched in the August 2026 Patch Tuesday; exploitation attempts began roughly six weeks later, days after technical details were disclosed, including attempts to plant web-shell backdoors. Added to CISA KEV Sept 25.
**Fix:** Apply August 2026 SharePoint updates — SE 16.0.19725.20522 / 2019 16.0.10417.20198 / 2016 16.0.5565.1001.
Source: https://www.securityweek.com/microsoft-sharepoint-flaw-cve-2026-65660-now-exploited-in-attacks/

### CVE-2026-67279 — MikroTik RouterOS SSH authentication bypass ("MikroTrick")
RouterOS SSH server advances to the connection phase after a client-initiated rekey without verifying authentication ever completed, giving unauthenticated command execution and file-write access. CERT.pl logged in-the-wild attacks starting Sept 2, 2026 — a day before MikroTik shipped a fix — with an estimated 122,500+ routers exposed. Added to CISA KEV Sept 25.
**Fix:** Upgrade to RouterOS 6.49.21 / 7.23.4 / 7.24.2, or disable/restrict the SSH service if patching is delayed.
Source: https://cert.pl/en/posts/2026/09/mikrotik-routeros-cve/

## Critical CVEs (NVD, CVSS ≥ 9.0, no confirmed exploitation)

### CVE-2026-86708 — Zoho ManageEngine Applications Manager hardcoded cloud credential (CVSS 3.1: 10.0)
A Google Cloud service-account private key is exposed inside the Applications Manager installer (versions ≤ 182200), letting an unauthenticated attacker impersonate the service account and access/modify associated cloud resources.
**Fix:** Upgrade to build 182300+; rotate any exposed GCP service-account keys.
Source: https://ccb.belgium.be/advisories/warning-multiple-vulnerabilities-zoho-manageengine-applications-manager-opmanager

### CVE-2026-93643 — Zimbra Collaboration Suite unauthenticated RCE via OnlyOffice (CVSS 3.1: 9.8)
When OnlyOffice/Document Editing is enabled, an unauthenticated attacker with access to a public Briefcase document can abuse unsigned save fields for path-traversal writes and command execution as the `zimbra` user.
**Fix:** Apply Zimbra's patched build; disable OnlyOffice integration if patching isn't yet possible.
Source: https://nflo.tech/knowledge-base/2026-09-25-cve-2026-93643-en/

### CVE-2026-86248 — Apache Tomcat CLIENT-CERT auth soft-fail bypass (CVSS 3.1: 9.8)
An incomplete fix for a prior CVE means CLIENT-CERT/OCSP authentication can silently soft-fail even when soft-fail is disabled, letting a network attacker bypass certificate authentication. Affects Tomcat 11.0.0-M14–11.0.25, 10.1.22–10.1.59, 9.0.92–9.0.121.
**Fix:** Upgrade to Tomcat 11.0.26, 10.1.60, or 9.0.122.
Source: https://www.sentinelone.com/vulnerability-database/cve-2026-86248/

## General News

### "SalesBleed" — three Salesforce Agentforce flaws enabled zero-click CRM data theft
Zenity Labs disclosed three Agentforce vulnerabilities exploitable via Salesforce's public Web-to-Lead forms: two allowed zero-click exfiltration of CRM data (including via DNS-based leaks) once an employee asked an Agentforce agent to process a poisoned lead, and a third let attackers impersonate a trusted Agentforce-connected Slack agent for internal phishing. Salesforce fully remediated the underlying Trusted URLs bypass by Aug 18, 2026 and reports no evidence of exploitation before the fix.
Source: https://www.securityweek.com/salesbleed-flaws-in-salesforce-agentforce-enabled-zero-click-data-exfiltration/
