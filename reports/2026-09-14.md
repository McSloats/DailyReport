**CVE-2026-51990 — Sogou Input Method (Tencent): One-Click RCE via URI Handler**
No official CVSS rating found, but impact is critical. ## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-82845 — Masteriyo LMS (WordPress): Insecure Deserialization to RCE**
CVSS 9.9. Versions before 3.4.1 fail to sanitize user-supplied metadata before deserializing it. A minimally privileged (Subscriber-level) account can inject arbitrary PHP objects and, via a bundled class, write and execute code on the server; a weaker unauthenticated variant of the same flaw yields arbitrary file write. No confirmed in-the-wild exploitation yet. **Fix:** update to Masteriyo LMS 3.4.1 or later; if not immediately possible, disable the plugin or restrict the metadata-deserialization feature.
Source: https://www.strix.ai/cve/CVE-2026-82845

**CVE-2026-81402 — DS Ad Rotator (WordPress): Unauthenticated Arbitrary File Upload**
CVSS 9.8. The plugin's image-upload handler (versions through 0.8) performs no capability check, nonce verification, or file-type validation, letting an unauthenticated attacker upload a PHP file to a web-accessible directory and achieve remote code execution — full site takeover. **Fix:** update past 0.8 once a patched release ships; until then, disable the plugin or block script execution in its upload directory at the web-server level.
Source: https://www.strix.ai/cve/CVE-2026-81402
