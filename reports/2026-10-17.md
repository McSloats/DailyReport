## 🔴 Actively Exploited / CISA KEV

### CVE-2026-102764 — BeyondTrust Remote Support Auth Bypass to Arbitrary File Upload
CVSS 9.3 · Zero-day, exploited since late Aug 2026 · KEV added Oct 16, 2026
An authentication-bypass-by-spoofing flaw in Remote Support appliances lets an attacker upload arbitrary files, leading to remote code execution. Mandiant/Google Threat Intelligence Group traced exploitation — underway as a zero-day since late August — to ARMORY CASTLE, a suspected China-nexus espionage actor previously tracked as UNC5221.
**Fix:** Apply BeyondTrust bulletin BT26-05-RS and update Remote Support to 24.3.1+. Cloud-hosted instances were auto-patched; self-hosted deployments need manual action.
Source: https://cloud.google.com/blog/topics/threat-intelligence/armory-castle-exploits-beyondtrust
Source: https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-urges-patching-critical-vulnerability-beyondtrust-remote-support

### CVE-2025-61624 — Fortinet FortiOS/FortiPAM/FortiProxy/FortiSwitchManager CLI Path Traversal
CVSS 6.5 (NVD) / 5.4 (Fortinet) · Exploited · KEV added Oct 16, 2026
An authenticated admin can escape the FortiOS CLI auto-script sandbox to write or delete arbitrary files. Unit 42 and Mandiant tie exploitation to UNC5820, which chained this bug — after an initial FortiManager compromise via the older FortiJump flaw (CVE-2024-47575) — to plant PEERSTITCH, a memory-resident implant inside FortiGate firewall processes with no files on disk.
**Fix:** Apply Fortinet advisory FG-IR-26-122 or the FMWP virtual patch (FG-VD-59270.0day); audit the trust relationship between FortiManager and managed FortiGate devices.
Source: https://securityonline.info/fortios-peerstitch-malware-fortimanager/

### CVE-2026-110447 — Nextcloud / Collabora Built-in CODE Server Unauthenticated Command Injection
CVSS v4 9.2 · Exploited since mid-Sept 2026 · Not yet in CISA KEV
The optional richdocumentscode app is vulnerable to command injection whenever its bundled document server isn't running. Attackers used the window to drop PHP webshells for about a month before the public advisory; Collabora quietly shipped a fix in version 26.4.303 in mid-September with no accompanying warning.
**Fix:** Update to Collabora Built-in CODE Server 26.4.303+, or remove the richdocumentscode app. Check the app's directory for unexpected PHP files.
Source: https://www.bleepingcomputer.com/news/security/hackers-exploit-collabora-rce-flaw-to-backdoor-nextcloud-servers/
