## Actively Exploited / CISA KEV

- **CVE-2026-59310** (CVSS 9.8) — Broadcom VMware vCenter, path traversal in the Syslog component leading to RCE. Disclosed 29 Jul; a suspected APT was exploiting it within 5 days, and by 7 Aug 361 servers across 47 countries were compromised (attackers using reverse SSH for persistence). No workaround exists — patch only.
  Source: https://www.scworld.com/news/critical-vmware-vcenter-flaw-actively-exploited-in-47-countries
- **CVE-2026-21962** (CVSS 10.0) — Oracle HTTP Server & WebLogic Proxy Plug-in. Unauthenticated attackers can access/modify critical data via crafted HTTP requests. Over 140,000 attack attempts logged in a 12-day window; a China-linked APT has used it against government networks in 100+ countries. Added to CISA KEV 24 Aug (federal deadline 27 Aug). **Fix:** apply Oracle's January 2026 CPU for HTTP Server/WebLogic Proxy Plug-in if not already installed.
  Source: https://thehackernews.com/2026/08/actively-exploited-oracle-weblogic-flaw.html
- **CVE-2026-8452** (CVSS 8.8) — Citrix NetScaler ADC/Gateway memory overflow on VPN/AAA virtual servers. Originally patched as a DoS bug in June, now shown to allow root RCE; attackers dropping web shells (`x.php`, `z.php`). Added to CISA KEV 26 Aug (federal deadline 29 Aug). **Fix:** upgrade to NetScaler 14.1-72.61 / 13.1-63.18 / 13.1-37.272 or later.
  Source: https://www.cisa.gov/news-events/alerts/2026/08/26/cisa-adds-six-known-exploited-vulnerabilities-catalog
- Also added to KEV this week (lower urgency, mostly legacy CVEs, deadline 9 Sep): CVE-2019-1068 (MS SQL Server RCE), CVE-2022-0995 (Linux kernel OOB write), CVE-2021-23758 (Ajax.NET deserialization), two 2015 Red Hat flaws.
