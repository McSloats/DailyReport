## Actively Exploited / CISA KEV

- **CVE-2026-82078** (CVSS 9.4) + **CVE-2026-81578** (CVSS 8.8) — PaperCut NG/MF pre-auth RCE chain. Improper access control in the web management interface (auth bypass) chained with unsafe dynamic class loading in database connection utilities gives unauthenticated attackers full RCE. Affects all supported PaperCut NG/MF versions; PaperCut has confirmed customer incidents. **Fix:** emergency patches released 28 Aug for v25/v26 (v24 same day); disconnect servers from the internet or restrict to trusted IPs until patched.
  Source: https://thehackernews.com/2026/08/attackers-chain-two-papercut-flaws-to.html
- **CVE-2026-60004** (CVSS 9.8) — Gitea diffpatch code injection. A repository writer (or, via default self-registration, an anonymous outsider) can plant a Git hook and run shell commands as the Gitea service account. Actively exploited to deploy cryptomining payloads; added to CISA KEV 25 Aug. Over 8,300 internet-exposed instances remained unpatched as of 28 Aug. **Fix:** upgrade to Gitea 1.27.1+ (affects 1.17–1.27.0); disable public self-registration if not needed.
  Source: https://www.helpnetsecurity.com/2026/08/26/gitea-cve-2026-60004-exploited-in-the-wild/
- Reminder: **CVE-2026-8452** (Citrix NetScaler ADC/Gateway, covered in yesterday's report) hits its CISA federal remediation deadline today, 29 Aug.

## Critical CVEs (NVD, 9.0+)

- **CVE-2026-18885 / CVE-2026-18886 / CVE-2026-74820** (all CVSS 10.0) — ServiceNow AI Platform: code injection, improper access control, and SQL injection respectively, each allowing unauthenticated code execution, privilege escalation, or arbitrary SQL against the instance database. Found via ServiceNow's own research/disclosure program; vendor reports no known exploitation. **Fix:** patches released 27 Aug — apply immediately to self-hosted/managed instances.
  Source: https://thehackernews.com/2026/08/three-cvss-100-servicenow-flaws-could.html
- **CVE-2026-65643** (Critical) — cPanel & WHM domain-parking flaw. Any authenticated account with parked/addon domain permissions can write arbitrary files anywhere on the server, leading to root code execution — a significant risk in shared/reseller hosting since one low-privilege tenant could compromise the whole server. Disclosed 27 Aug; not yet in CISA KEV, exploitation not confirmed. **Fix:** apply the vendor update across all supported cPanel & WHM versions.
  Source: https://thehackernews.com/2026/08/critical-cpanel-flaw-could-let-one.html
