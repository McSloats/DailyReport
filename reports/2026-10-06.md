## Actively Exploited / CISA KEV

### CVE-2026-76504 — Cisco Catalyst SD-WAN Manager authentication bypass (CVSS 9.8)
An unauthenticated remote attacker can abuse improper URL-encoding handling (CWE-177) in the `j_security_check` endpoint to obtain full admin API access on Catalyst SD-WAN Manager. Cisco confirmed active exploitation beginning in September; CISA added it to KEV on Sept 30. No workaround exists — only the patched releases close it.
**Fix:** Upgrade to Catalyst SD-WAN 26.2.1, 26.1.2.1, 20.18.4.1, 20.15.6.1, 20.12.8.2, or 20.9.10.1.
Source: https://www.bleepingcomputer.com/news/security/cisco-warns-of-new-sd-wan-authentication-bypass-zero-day-exploited-in-attacks/

### CVE-2026-104286 — Fortinet FortiMail path traversal zero-day (CVSS 9.8)
Improper NULL-byte neutralization lets attackers manipulate file paths to read or write files outside intended directories on FortiMail. Fortinet confirmed in-the-wild zero-day exploitation; CISA added it to KEV on Oct 1. Affects FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, and 7.2.0–7.2.9.
**Fix:** Upgrade to a fixed FortiMail release per Fortinet's advisory; restrict management-interface exposure in the interim.
Source: https://theregister.com/security/2026/10/02/fortinet-sounds-the-alarm-over-actively-exploited-fortimail-zero-day/5300803

### CVE-2026-102489 / CVE-2026-102490 — Zammad session fixation chained to root privilege escalation (CVSS 9.4 each)
CVE-2026-102489 lets an attacker fix or predict a session identifier and ride it into an authenticated context without credentials, reaching code execution as the low-privileged `zammad` service account (versions 6.3.0–6.5.4). CVE-2026-102490 then lets that foothold escalate to root on the host. CISA confirmed active exploitation of the chain and added both to KEV on Oct 2; Zammad says 7.0+ is unaffected by the first flaw.
**Fix:** Upgrade to Zammad 6.5.5/7.2.0 or later; hunt for signs of root compromise on any internet-facing instance running 6.5.4 or earlier.
Source: https://securityaffairs.com/200248/security/u-s-cisa-adds-zammad-gmbh-zammad-flaws-to-its-known-exploited-vulnerabilities-catalog.html

### CVE-2026-61500 — Rejetto HFS admin session forgery via weak PRNG
Rejetto HTTP File Server (3.0.0–3.2.0) derives its session-cookie signing key from the non-cryptographic `Math.random()` generator and leaks generator output to unauthenticated clients during login, letting an attacker reconstruct the key, forge an admin session, and execute code. Exploitation began Oct 3 — one day after a technical write-up was published — including reconnaissance from China Telecom-linked IPs against honeypots in Japan and the US. Not yet in CISA KEV.
**Fix:** Upgrade to HFS 3.2.1 or later.
Source: https://thehackernews.com/2026/10/attackers-target-rejetto-hfs-flaw-that.html

## Critical CVEs (NVD, CVSS ≥ 9.0)

### CVE-2026-21589 — Atlassian Data Center unauthenticated arbitrary file read (CVSS 9.3)
A path-traversal flaw across eight self-hosted Atlassian Data Center products (Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo, Crowd, Crucible, Fisheye) lets an unauthenticated attacker read specific files inside the web-app root if they know the exact filename/path. Disclosed Oct 5; no directory listing/enumeration is possible. Atlassian Cloud is already patched.
**Fix:** Upgrade self-hosted instances per Atlassian's advisory; take internet-exposed instances offline or block external access until patched.
Source: https://thehackernews.com/2026/10/critical-atlassian-flaw-lets.html

### CVE-2026-104334 / CVE-2026-93674 — IBM Langflow OSS unauthenticated RCE (CVSS 9.8 each)
IBM's Oct 2 bulletin for Langflow OSS (an AI agent/workflow builder) disclosed 25 flaws, including two unauthenticated RCE bugs reachable over the network with no privileges or user interaction: CVE-2026-104334 (improper control of code generation) and CVE-2026-93674 (OS command injection). Versions 1.0.0–1.12.2 affected.
**Fix:** Upgrade to Langflow 1.12.3 or later.
Source: https://securityonline.info/langflow-vulnerabilities-1-12-3/

### CVE-2026-86360 — Dell System Update path traversal to root code execution (CVSS 9.6)
Dell System Update (DSU) versions before 2.3.0.0 fail to validate user-supplied input in the CLI deployment tool, allowing path traversal that leads to unauthorized filesystem access and arbitrary code execution with root privileges on PowerEdge servers (Linux and Windows). Dell reports no active exploitation so far.
**Fix:** Update to Dell System Update 2.3.0.0 or later.
Source: https://www.bleepingcomputer.com/news/security/new-dell-system-update-flaw-lets-hackers-gain-root-privileges/

## Vendor Advisories

### Microsoft Exchange Server — out-of-band patch for cross-mailbox access flaw (CVE-2026-96940, CVSS 8.8)
A weak-authorization flaw lets an authenticated attacker escalate privileges and read other users' mailboxes/attachments within the same Exchange organization. Found internally; Microsoft says it is not aware of active exploitation but notes this bug class has been exploited before, and reissued the update after an initial release sequencing problem. Exchange Online is already protected; no cross-tenant access is possible.
**Fix:** Apply the out-of-band update for Exchange Server Subscription RTM, Exchange 2019 CU14/CU15, or Exchange 2016 CU23.
Source: https://www.helpnetsecurity.com/2026/10/05/exchange-server-vulnerability-cve-2026-96940/

## General News

### Denmark's national population register breached — 8.8 million people's data exposed
Denmark's Central Person Register (CPR) administration discovered Oct 2 that attackers had abused a Danish company's legitimate access since sometime in September to run high-volume automated lookups, harvesting names, addresses, and CPR numbers for roughly 8.8 million current, deceased, and emigrated citizens. Access has been revoked and the incident reported to the Danish DPA; a full security review of CPR access controls has been ordered.
Source: https://cybernews.com/security/denmark-cpr-data-breach-exposes-millions/

### South Africa's air traffic control operator finds ransomware-linked malware in OT network
ATNS, which manages roughly 10% of the world's airspace, detected ransomware-precursor malware in operational-technology systems supporting aviation weather services, with indications of data exfiltration to China-linked external IPs. ATNS says its technical team contained the activity and is bringing in outside cyber-forensics help; the investigation also covers possible insider data theft at airports in South Africa and Mozambique.
Source: https://mybroadband.co.za/news/security/670359-china-linked-hackers-attacked-south-africas-air-traffic-control-system.html
