## Actively Exploited / CISA KEV

PaperCut (KEV Aug 31), SonicWall SMA1000, and JFrog Artifactory CVEs are already on CISA's KEV list; the Elementor Pro flaw is under heavy active exploitation but not yet KEV-listed.

### CVE-2026-81578 + CVE-2026-82078 — PaperCut NG/MF chained pre-auth RCE, schools targeted (CVSS 9.4)
An access-control bypass (81578) lets an unauthenticated attacker rewrite PaperCut server configuration; chained with an unsafe dynamic-class-loading bug (82078), it lets that attacker load an arbitrary Java database driver and execute code as the PaperCut service — no credentials, just a reachable IP. Attackers are actively hitting K-12 schools and universities across the US and Europe, creating privileged accounts and running Metasploit/Meterpreter payloads and registry-hive collection tools for credential theft. **Fix:** update to the latest PaperCut NG/MF patch immediately; treat any exposed instance as compromised and rotate credentials/keys.
Source: https://thehackernews.com/2026/09/attackers-exploit-papercut-flaws-to.html

### CVE-2026-83548 + CVE-2026-83549 — SonicWall SMA1000 SSRF chained to OS command injection (zero-days) (CVSS 10.0)
An unauthenticated SSRF in the SMA1000 Work Place interface (83548, CVSS 10.0) can be chained with an OS command-injection bug in the Appliance Management Console (83549) to reach unauthenticated remote code execution. SonicWall confirmed active exploitation at disclosure on Sept 1 — the third exploited SMA1000 zero-day chain since December — and both CVEs are now KEV-listed. **Fix:** apply SonicWall's SMA1000 firmware update immediately; review AMC and Work Place access logs for signs of prior compromise.
Source: https://thehackernews.com/2026/09/attackers-exploit-two-sonicwall-sma.html

### CVE-2026-82329 — JFrog Artifactory authentication bypass to admin token forgery (CVSS 9.8)
An authentication-bypass flaw in Artifactory's default configuration lets an unauthenticated network attacker mint themselves administrator tokens with no user interaction. WatchTowr observed in-the-wild exploitation within days of disclosure; admin access to a software-supply-chain system opens the door to tampering with build pipelines and pushing malicious artifacts downstream. **Fix:** update self-hosted Artifactory to 7.161.20 or later — JFrog has already patched cloud instances.
Source: https://thehackernews.com/2026/09/attackers-exploit-critical-jfrog.html

### CVE-2026-32475 — Elementor Pro (WordPress) file-upload validation bypass to webshell (CVSS high, not yet scored in NVD)
Faulty validation of file-upload arrays in Elementor Pro forms (≤4.2.1) lets an attacker submit an empty file as the first array element and a malicious PHP file as the second, causing the plugin to skip validating the rest of the upload. The webshell lands under `/wp-content/uploads/elementor/forms/`. Wordfence has blocked nearly 200,000 exploitation attempts since the Aug 19 patch shipped. **Fix:** update Elementor Pro to 4.2.2 or later; scan `uploads/elementor/forms/` for unexpected PHP files.
Source: https://www.bleepingcomputer.com/news/security/critical-elementor-pro-flaw-exploited-to-take-over-wordpress-sites/

## Critical CVEs (NVD, CVSS ≥ 9.0, not yet confirmed exploited)

### CVE-2026-20212 — Cisco Nexus 9000 (Silicon One) unauthenticated root RCE (CVSS 9.8)
Nexus 9000 switches built on Cisco's Silicon One ASIC bind an internal service to an unrestricted IP address, leaving TCP ports 43210 and 43211 reachable on the default Layer-3 VRF; anyone who can reach either port can send crafted input that executes as root. Cisco disclosed the flaw Sept 2 with no evidence of exploitation so far, but has also shipped a Live Protect signature (lp00031) as a stopgap. **Fix:** upgrade to a fixed NX-OS release; until then, apply Cisco's Live Protect shield lp00031 and restrict access to ports 43210/43211.
Source: https://thehackernews.com/2026/09/critical-cisco-nexus-9000-flaw-lets.html
