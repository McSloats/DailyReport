## Critical CVEs (NVD, CVSS ≥ 9.0)

### CVE-2026-76744 / 76742 / 76745 / 76746 / 76747 — HPE Aruba Networking AOS-S multiple memory-corruption & auth-bypass flaws (CVSS up to 9.8)
A batch of flaws disclosed Oct 6 in HPE Aruba Networking's AOS-S switch operating system: CVE-2026-76744 (CVSS 9.8) is an unauthenticated buffer overflow enabling arbitrary code execution; CVE-2026-76742 (CVSS 9.8) is an unauthenticated bypass of the web management interface's authentication; CVE-2026-76745 (CVSS 9.6) is an adjacent-network memory-corruption flaw allowing code execution; CVE-2026-76746 (CVSS 9.3) and CVE-2026-76747 (CVSS 9.1) are adjacent-network buffer overflows that can expose memory contents and crash the device. No public proof-of-concept or CISA KEV listing has been confirmed as of this writing; details here come from a third-party CVE tracker, as no official HPE bulletin for this batch was located.
**Fix:** Check HPE's Security Bulletin Library (support.hpe.com) for the AOS-S bulletin covering this batch and apply the listed fixed firmware; where none is yet published, restrict management-interface access to trusted networks only.
Source: https://www.thehackerwire.com/vulnerability/CVE-2026-76744/

### CVE-2026-76753 — HPE Aruba Networking ClearPass Policy Manager format-string flaw (CVSS 9.8)
Also disclosed Oct 6: a format-string vulnerability in a ClearPass Policy Manager service interface could let an unauthenticated network attacker corrupt process memory and potentially achieve arbitrary code execution, requiring no privileges or user interaction. No public exploit code or active-exploitation reports have been confirmed yet; as above, this is sourced from a third-party tracker pending an official HPE bulletin.
**Fix:** Check HPE's Security Bulletin Library for the ClearPass advisory covering this CVE and apply the fixed release; restrict ClearPass admin/service interfaces to trusted management networks in the meantime.
Source: https://www.thehackerwire.com/vulnerability/CVE-2026-76753/
