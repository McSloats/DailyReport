## 🔴 Actively Exploited / CISA KEV

**CVE-2026-76461 — Cisco Secure Email Gateway: SQL Injection to Unauthenticated Root RCE**
CVSS 9.8. Insufficient input validation in the AsyncOS email-parsing logic lets an unauthenticated attacker send a single crafted email containing malicious SQL statements to a Secure Email Gateway appliance and execute arbitrary commands with root privileges — no login, no user interaction. Cisco confirmed active exploitation and CISA added the flaw to its KEV catalog on Sept 14, giving federal agencies until Sept 17 to patch. Four related but not-yet-exploited critical bugs (CVE-2026-76440, -76441, -20353, -76443) were fixed in the same release. **Fix:** upgrade to a fixed AsyncOS release immediately; Cisco has published no workaround.
Source: https://thehackernews.com/2026/09/cisco-secure-email-gateway-flaw.html

**CVE-2026-85706 — GitLab CE/EE: Unauthenticated Path Traversal to Arbitrary File Read**
CVSS 10.0. Missing authentication enforcement and improper path confinement in the repository commits API let an unauthenticated attacker read arbitrary files — including credentials and secrets — from a vulnerable self-managed GitLab server, no account or user interaction required. GitLab patched it Sept 10; researchers observed internet-wide probing starting the next morning, and CISA added it to the KEV catalog on Sept 11 under a three-day federal patch deadline. GitLab.com and GitLab Dedicated are already protected. **Fix:** self-managed instances on 18.7–19.1.7, 19.2–19.2.5, or 19.3–19.3.1 must upgrade to 19.1.8, 19.2.6, or 19.3.2 respectively; rotate any credentials that may have been exposed.
Source: https://www.rapid7.com/blog/post/etr-cve-2026-85706-critical-gitlab-path-traversal-exploited-in-the-wild/

## 🟠 Critical CVEs (NVD, CVSS ≥ 9.0)

**CVE-2026-81648 — CryptoPayment Gateway (WordPress): Missing Authorization to Full Site Compromise**
CVSS 10.0. Versions 1.2.1–1.2.2 expose an administrative AJAX endpoint with no authorization check, letting an unauthenticated visitor delete arbitrary files, overwrite the payment-gateway configuration, and recover stored wallet credentials in cleartext. No confirmed in-the-wild exploitation yet, but the combination of file deletion and credential exposure on a payments plugin makes this a high-value target. **Fix:** update to the latest release restoring authorization checks on all AJAX actions; until then, block the vulnerable AJAX action at the WAF or web-server level.
Source: https://www.strix.ai/cve/CVE-2026-81648

**CVE-2026-90692 / CVE-2026-90693 — D-Link DIR-878: Unpatched Remote Stack Overflows**
CVSS 9.9 each. Two remotely triggerable stack-based buffer overflows — one in the Dynamic DNS IPv6 settings handler, one in the WAN settings handler — let a network attacker corrupt stack memory via oversized values in router configuration requests. D-Link ended support for the DIR-878 in 2021 and has confirmed no patch is coming for either flaw. **Fix:** no vendor fix exists; remove the device from service or isolate it from untrusted networks and replace with a supported router.
Source: https://5gstore.com/blog/2026/09/14/dlink-dir-878-cve-2026-90692-90693-critical-no-patch/
